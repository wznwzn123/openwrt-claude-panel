OpenWrt 路由器的手机控制面板，可选接入 Claude 用对话管理路由器。

最低版本：v5.0.0【必须更新】（这次所有人都要更新到 5.0：面板会弹出更新窗口，点「一键更新」就行，设置都保留、不断网）

## 这个版本的更新

**更省闪存、更省内存，所有路由器、所有安装包都一样，功能一个不少：**
- **面板压缩存放**：面板网页在闪存里只放压缩过的一份，发给手机也是压缩的（浏览器自己解开），打开更快；面板装好后占的闪存从约 0.9 MB 降到约 0.6 MB。万一哪台路由器用不了压缩方式，安装时会自己发现、照旧存原来的
- 面板网页、二维码组件、图标都精简过（显示效果一样）
- 手机里已经有面板时，路由器上没变就不再重新下载，开面板更省流量
- 设置备份最多留 40 份、总共最多 4 MB（闪存剩不到 16 MB 时 1 MB），最新的 5 份一定留着，不会越积越多
- 装完、更新完自动删掉 /tmp 里的安装包（/tmp 在内存里，以前要等重启才释放约 1–2 MB）；面板的请求日志上限从 300 KB 降到 64 KB
- **低配路由器自动认出来**：安装时会显示「这台路由器：内存 X MB · 闪存剩 Y MB · N 核」；内存 256 MB 及以下的自动开启省资源设置——隧道程序 cloudflared 更省内存，单核或小内存的路由器上概览刷新放慢一点（4 秒 → 8 秒），功能不变
- **低配手机自动关掉毛玻璃效果**（内存 2 GB 及以下或 4 核及以下的安卓），滑动更顺；好的手机和苹果手机照旧

**其它：**
- **卸载更方便**：在终端里直接输入 `cmcp-uninstall` 就能卸载，不用再找安装包；卸载后要彻底删除设置，按提示运行一条命令
- **实时联系开发者**：开发者不在线时，你发的消息会马上收到一条自动回复，告诉你开发者看到后会尽快回；开发者本人回的标「开发者」，自动回复标「自动回复」
- 面板万一出了程序错误，会自动告诉开发者（只带错误内容、手机类型、屏幕大小和面板版本，不带网址和密钥），方便更快修好
- 开发者发的公告可以定时发布
- 开发者这边：管理后台加了两步验证（登录时输验证器 App 里的 6 位码）、每天自动备份数据（保留 7 天）、开发者不在线时手机推送和邮件提醒新消息、对话可以标「已解决」、公告能看到大概多少台路由器收到和看过；隐私说明也更新了：写明了程序错误上报、公告统计（每台路由器一个随机编号，不跟账号、IP 关联）和每日数据备份

v4.0.1 的更新：
- 小屏手机（iPhone SE 这类 320 宽的屏幕）上排版修好了：「断线记录」里宽带、外网、DNS 这些状态不再被截成一个字；节点页「测速」按钮不再竖着折成两行，「代理集」那一行的「更新」按钮不再伸出卡片
- 空列表的提示文字和卡片边留出距离

v4.0.0 的更新：
- **新增「通知」**：顶栏多了一个铃铛，侧边栏「消息与帮助 → 通知」。路由器出的问题和自动修复、云端监测（断电断网）、托管服务（续期、到期）、开发者的公告、版本更新、反馈进度、开发者的回复，全部汇总在一个地方，按天排好，没看过的标「新」，铃铛上显示数字
  - 开发者发的**重要公告**会推送到手机，打开面板时也弹一次；普通公告只在「通知」里看
  - 自建版也能收到公告
- **新增「实时联系开发者」**：侧边栏「消息与帮助」和「通知」页都有入口。遇到问题、想要的新功能，直接在面板里跟开发者对话，可以发截图；开发者回复后推送到手机，开着这一页几秒内就能看到。路由器型号和面板版本会自动带上。托管版和自建版都能用
- **修好了「闪存只剩 0 MB」的误报**：有些固件（比如 EzOpWrt）的分区名字很长，以前安装时会把剩余空间读成 0 MB、装不上。现在能正确读出来；万一真不够，会把各分区的情况列出来
- 终端里安装失败、按 y 上报时，**必须填邮箱**（处理结果会发到这个邮箱，输错了会让你重新输）
- 面板的通知页、对话页都按手机、平板、电脑（安卓、苹果、Windows、Mac）分别排好版，深色模式也一样
- 开发者这边：托管服务的管理后台换成了新版（按区分类：工作台统计、实时对话、问题反馈、公告、路由器、账号、开通与续期、访问统计、登录记录和各类日志）；隐私说明也更新了：4.0 起官网记录登录 IP（90 天后删）和访客 IP（30 天后删），只用来防盗号、防刷量

v3.1.3 的更新：

v3.1.2 的更新：

v3.1.1 的更新：

- **开发者有新进展，提醒更快了**：以前要重新打开面板、还可能要等 20 分钟才弹出来；现在面板开着时一分钟内就会提示，从后台切回来马上查；开了推送的手机会直接收到推送。标了「已收到」也会提示
- **官网查进度更方便**：首页最上面就能输受理编号查；登录后账号页有「我的反馈」，列出自己路由器发的和登录后报告的
- **官网报告问题可以留邮箱**：登录了会自动填账号邮箱，提交后马上收到一封带受理编号的确认邮件，处理好了也会发邮件
- 发给你的邮件都写上了受理编号和查进度的网址

v3.1.0 的更新：
- **闪存小的路由器也能装了**：像 360T7 这种闪存只剩 20 MB 左右、又没有 USB 的，以前装不下 cloudflared（约 30 MB）。现在会自动用「小闪存模式」：cloudflared 不占闪存，开机后下载到内存里运行，下载完先核对校验值，对不上不用。闪存够的路由器还是跟以前一样
- **装软件时 opkg 崩溃会自己重试**：有些固件自带的 opkg 一装东西就崩（Segmentation fault），安装脚本会清掉缓存、重新更新软件源再试一次；还不行就说清楚原因，提示换稳定版固件
- **反馈有编号，能看处理到哪一步了**：在面板里发反馈、终端里上报安装失败、官网报告问题，都会给一个 8 位编号
  - 进度条分三段：反馈成功 → 开发人员已收到 → 已修复。修不了的会如实写「无法修复」，并说明原因
  - 开发者写的说明都在下面的完整记录里，编号旁边能一键复制
  - 不用注册、不用邮箱：面板里的反馈，开发者有新说明时打开面板会自动弹出来；终端上报的，下次运行安装命令时最上面会显示；也可以在官网底部「查处理进度」输入编号查
- 面板里发完反馈，会弹出编号和「查看处理进度」，不再只闪一下提示
- 很长的开发者说明会先折叠，点「查看全部」展开

v3.0.3 的更新：

- **问题反馈 / 建议**：面板「系统操作」里新加的，遇到问题、想要什么功能直接写给开发者，可以附上路由器信息方便查问题
- **托管版装完只给一个链接**：手机打开后点「绑定官网账号」，登录或注册后自动绑定、自动拿到登录码，点「打开面板」就进去了；其他地址都放进「备用信息」

## 快速安装（只用手机）

手机连家里 Wi-Fi → 路由器后台「服务 → 终端」→ 粘贴（把 `hosted-ai` 换成你要的版本代号：`hosted-noai`、`ai-lite`、`ai-full`、`noai-lite`、`noai-full`）：

```sh
cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted-ai.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh
```
