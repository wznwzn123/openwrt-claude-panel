隐私政策

适用于托管服务（本网站和它开通的专属网址）。最后更新：2026 年 11 月 7 日

一句话：路由器的设置和上网情况留在你的路由器上；托管服务存的是让服务跑起来必需的东西（账号、路由器登记、运行状态、推送订阅），以及你主动开启或提交的东西（云端备份、问题反馈）。你的上网记录不会上传。自己搭建（用自己的 Cloudflare）的，数据都在你自己的账号里，这份政策不适用。

存了哪些数据、存多久

数据里面有什么、用来做什么存多久
官网账号邮箱、密码（加盐后用 PBKDF2 算的哈希，看不到原密码）、注册和最近登录时间、登录状态、绑定了哪几台路由器、试用领取记录。用来登录、拿登录码、续期。到你注销账号为止；注销后 30 天内能恢复，之后彻底删除
路由器登记专属网址编号、路由器名字（主机名）和型号、开通和最近上线时间、到期时间、用的哪个邀请码。用来开通网址、判断是否在线、到期提醒。卸载时马上删除；90 天没上线放进回收站，30 天后彻底删除
运行状态路由器每分钟报一次：宽带、外网、DNS、隧道、面板、代理插件是不是正常。用来判断断电断网、推送提醒。不含上网记录、访问了哪些网站。只留最近 300 条状态变化；删除路由器时一起删
推送你在手机上打开推送时的订阅地址；开了微信推送的，还有 PushPlus 的 token。到你关掉推送或删除路由器为止
云端备份路由器全部设置的整包（包括 Wi-Fi 密码、宽带账号、面板登录密钥）。开启加密后（v2.0.8 起）只存路由器加密过的密文，托管服务看不到内容；没开启加密的原样存着。最多留最近 10 份；你在面板里删、关掉云端备份或卸载时删除
问题反馈、报告你写的内容、联系方式、截图；面板里发的还有你选择附上的路由器信息（面板版本、代理插件等，不含密钥和网址）和绑定账号的邮箱。用来回复和修问题。只留最近 300 条，处理后可以删除
续期申请申请表里填的内容和账号邮箱。用来审核续期。审核记录留在管理后台
操作记录管理员和系统做了什么（开通、续期、删除等），带路由器编号或账号邮箱。用来查问题。只留最近 500 条
限次记录为了防暴力破解和刷量，按 IP 或邮箱记次数。两天内自动删除

不收集什么

  • 上网记录、访问的网站、流量统计：只在你的路由器上，不上传（流量统计也不在云端备份里）。
  • 面板里的操作内容：面板的请求经 Cloudflare 隧道直接到你的路由器，托管服务的程序不经手、不记录。
  • 没有广告、统计、跟踪代码。

交给了谁

托管服务没有出售或分享你的数据。下面这些服务商会经手一部分数据，它们按自己的隐私政策处理：

  • Cloudflare：网站、隧道和上面所有数据的存储都在 Cloudflare 上。在外面打开面板的流量经 Cloudflare 加密转发，Cloudflare 技术上能看到内容。数据存放的服务器可能在中国大陆以外。
  • Resend：发验证码邮件、给管理员的提醒邮件（会经手你的邮箱地址和邮件内容）。
  • 手机和浏览器的推送服务（如 Google、Apple、Mozilla）：推送内容是加密的，推送服务看不到。
  • PushPlus：只在你开了微信推送时。推送内容（比如「新设备连上了」会带设备名、IP 和 MAC 地址）原样交给 PushPlus 发到微信。
  • GitHub：安装包和更新从 GitHub 下载，下载时 GitHub 会看到路由器的 IP。
  • Anthropic（Claude）：只在 AI 版、你把连接器加到 Claude 时。Claude 按你的对话读取和操作路由器，相关内容按 Anthropic 的政策处理。

你能做什么

  • 看：账号页能看到绑定的路由器和到期时间；面板「云端备份」页能看到每一份备份。
  • 导出：云端备份可以在面板里下载到手机；其他数据要导出，用报告表单告诉我们。
  • 删除：账号页可以注销账号；面板里可以删备份、关推送、关云端备份；路由器上运行卸载脚本，这台路由器在云端的数据马上删除。其他的用报告表单要求删除。

家长控制

面板的「暂停上网」可能用在孩子的设备上。要不要用、对哪台设备用，由家长决定和设置；托管服务不收集被暂停设备的上网内容。

变更和联系

这份政策有变化时会更新本页和上面的日期。有问题请用报告表单（选「隐私和数据」）。
