# 「一根线」设计说明（video-shotcraft 自主自由创作模式）

## 0. 产品简报与约束

- **主题**：OpenWrt Claude Panel 的插件本身、它的更新、坚持和做事的理念。
- **画幅 / 时长**：16:9，1920×1080，30fps，81.6 秒（34 小节 × 2.4 秒，100 BPM）。
- **事实来源**：全部来自本仓库（README、tools/release-notes.md、git 历史）。片中数字：
  - 94 次提交：`git rev-list --count HEAD`；
  - 20 个版本：v1.0 → v3.1.1；
  - 28 次凌晨提交：提交时间在 0:00–5:59 之间的（北京时间）；
  - 24,236 行新增：`git log --shortstat` 的 insertions 合计，代码和文档都算在内；
  - 11.02 – 11.06 没有提交。
- **大陆平台发布要求（按 视频.md 只保留这一部分）**：
  - 功能只说真实有的，不用「绝对安全 / 永不掉线 / 百分之百」这类绝对化说法；
  - 不用暗语或换个说法去掩盖业务性质：片中**不讲**代理、订阅这一块，而不是换个名字讲；
  - 面板截图用的演示路由器没装代理类插件，侧边栏按真实菜单显示，代理类插件名一个都不出现；
  - 提交长卷由 `tools/commits.py` 生成，凡是提交说明里带代理、节点、订阅一类字眼的提交（94 条里有 10 条）不上画面；
  - IP、MAC、域名、账号、密钥：截图全部用演示数据，没有真实信息；
  - 凡是出现面板界面的镜头，左下角都写「界面为真实面板 · 数据为演示数据」。

## 1. 视觉方向

一根线贯穿全片：**一盏「在线」绿灯 → 一笔画出产品图标 → 围出窗口 → 变成时间轴 → 停更那五天变成虚线 → 重新点亮 → 划掉做不到的承诺 → 最后再画一次图标**。

| 来源 | 用了什么 | 怎么改的 |
|---|---|---|
| mg-styles-15 · 12 弥散渐变 / 玻璃拟态 | **原片的 WebGL 着色器原文照搬**（`src/gl/shaders.ts`）：极光 FS_AURORA（simplex 噪声扭曲、7 个色斑沿贝塞尔闭环漂移、极光帘纹、光点）、FS_LENS 液态玻璃透镜（SDF 斜面、7 波段色散折射、菲涅尔、高光）、FS_FINAL（泛光、颗粒、暗角、抖动防色带）；渲染管线照 `main.js`（`src/gl/AuroraGL.tsx`）。另有 DOM 磨砂玻璃卡（5–10% 白填充 + 1px 内描边 + 大圆角 + 背景模糊） | 7 个色斑的结构和路径不变，颜色换成产品图标（`src/www/panel/icon.svg`）的紫 #6a4dff、蓝 #2f6bff、青 #00c2d8；三次大冲击时极光里荡开一圈光波（uRipple）；液态玻璃透镜只在收尾出现一次，成为图标的玻璃底座。面板本身就是磨砂玻璃主题，片子和产品是一套视觉 |

**设计 tokens**（`src/lib/look.tsx`）：底色 #05060d；正文 #f4f6ff；「在线」绿 #34c759、品牌蓝 #0a84ff（都取自面板 CSS 变量）；

动效的主缓动用面板自己的 `--spring: cubic-bezier(.32,.72,0,1)`，所以片子的「动作嗓音」跟产品一样。

## 4. 不用旁白、不用 video-talkcraft 的原因

video-talkcraft 是口播视频流程：它要一条成品配音（或者用付费的 Fish Audio 合成），再做字级时间戳。
这支片的叙事完全由画面和字承担，加旁白会和屏幕上的字重复；另外它的许可证是 PolyForm Noncommercial 1.0.0，这支片是产品推广，不适合用。所以只读了它的流程，没有用它的代码和素材。
