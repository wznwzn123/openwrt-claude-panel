# openwrt-claude-panel

OpenWrt 路由器的**手机控制面板**（PWA，可添加到主屏幕），还可以选择接入 **Claude**，用中文对话管理路由器。

🌐 **官网：[yrlove520.com](https://yrlove520.com)** · 托管版（输邀请码就有专属网址）、账号登录、安卓 App 下载都在这里。

- 手机面板覆盖日常要用的一切：OpenClash 节点和订阅、设备管理、流量统计、测速、断线记录、文件管理、终端……不用再在手机上缩放 LuCI。
- AI 版：在 Claude 里说一句「把奈飞切到新加坡节点」「看看谁在占网速」「给这台设备晚上 11 点断网」，它就能直接在路由器上操作。不想用 AI 就装纯面板版。
- 全部跑在路由器自带的 `ucode` + `uhttpd` 上，**不需要 Python / Node / Docker**，占用很小。
- 通过 Cloudflare 隧道访问：**不用公网 IP、不用开端口**。

> ⚠️ 安装后得到的「登录地址」里带着密钥，拿到它就等于拿到路由器的 root 权限。请当作密码保管，不要发给别人、不要截图分享。详见下方「安全说明」。

## 简洁版教程：5 分钟装好（托管版，只用手机）

> 想看每一步的截图和说明：[📱 手机教程（详细版）](docs/install-phone.md)

**你需要：** 一台 OpenWrt 22.03 以上的路由器（Kwrt、ImmortalWrt 都行）、一部手机、一个**邀请码**（找提供托管服务的人要）。

1. **打开路由器的终端**：手机连上家里的 Wi-Fi，浏览器打开路由器后台（比如 `http://192.168.1.1`）→「服务」→「终端」，用 `root` 和路由器密码登录。后台没有「终端」的话，用手机 SSH 软件（JuiceSSH、Termius）连 `root@路由器地址`。
2. **粘贴安装命令**，回车：
   ```sh
   # ⚠️ 下面的 hosted-ai 决定装哪个版本，对照下面的表换成你要的代号，其他地方别动
   cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted-ai.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh
   ```
3. **输入邀请码**：屏幕出现「邀请码」时粘贴进去，回车。
4. **装完会显示**：专属网址、登录地址、自动登录链接、（AI 版）Claude 连接器地址，最下面是大字的**配对码**和绑定链接。把这些地址存好（别发给别人）。
5. **打开面板**：手机浏览器打开「自动登录链接」。托管版为了安全，会让你**输入登录码**——先放着别关。
6. **绑定官网账号、拿登录码**：打开终端里的绑定链接（`https://yrlove520.com/app?pair=…`），登录或注册官网账号，自动绑定，并且**自动显示登录码**；点「打开面板」就自动填好了。之后「添加到主屏幕」（或者装[安卓 App](#安卓-app)）。
7. **AI 版**：Claude → 设置 → 连接器 → 添加自定义连接器，地址填「**Claude 连接器地址**」（不是登录地址）。
8. **开推送**：面板 →「断线记录」→「手机通知」→「开启通知」。

装好后家里其他手机：在已登录的手机上「系统操作 → 添加新手机」，新手机扫码；托管版第一次打开还要输一次登录码（官网账号页 → 这台路由器下面「获取登录码」）。

> **两个「终端」别弄混：** 安装、`cmcp-pair`、`cmcp-logincode` 这些命令要在**路由器后台的终端**里运行（LuCI「服务 → 终端」，或者 SSH），用户名 `root`，密码是路由器后台密码。手机面板里也有个「终端」，那是装好以后在面板里用的，**输入 `password` 之类的登录信息是没用的**。

## 运行要求

- OpenWrt 22.03 或更新（需要 `ucode`；Kwrt、ImmortalWrt 等衍生版本同样可用）
- 约 2 MB 闪存空间；`cloudflared` 本身约 30 MB，空间不够请先扩容 overlay
- [OpenClash](https://github.com/vernesong/OpenClash)：可选，但节点、订阅、规则、测速分流等功能依赖它
- 「设备暂停上网」目前使用 `iptables`（fw3 或装了 `iptables-nft` 的 fw4）

安装脚本会自动补装缺少的依赖：`ucode ucode-mod-fs ucode-mod-uci uhttpd curl cloudflared`。

## 安装

**只用手机：** 照上面的[简洁版教程](#简洁版教程5-分钟装好托管版只用手机)或[📱 手机教程](docs/install-phone.md)。

**用电脑：** 每个版本都有一步一步的教程：[托管版](docs/install-hosted.md) · [AI 精简](docs/install-ai-lite.md) · [AI 完整](docs/install-ai-full.md) · [纯面板精简](docs/install-noai-lite.md) · [纯面板完整](docs/install-noai-full.md)。安装包里的 `INSTALL.md` 也是同一份。简单来说：

```sh
scp openwrt-claude-panel-ai-lite.tar.gz root@192.168.1.1:/tmp/
ssh root@192.168.1.1
cd /tmp && tar xzf openwrt-claude-panel-ai-lite.tar.gz && cd openwrt-claude-panel
sh install.sh
```

装完会打印手机面板地址、登录地址，AI 版还会单独打印「Claude 连接器地址」。

也可以用参数免交互安装：

```sh
sh install.sh --invite 邀请码                # 托管版：邀请码直接写在命令里
sh install.sh --ai --lite --tunnel-token <隧道token> --domain router.example.com
sh install.sh --no-ai --full --tunnel-token <隧道token> --domain router.example.com --cloud-url https://router.example.com/cloud
```

### 隧道：两种方式

| | 临时隧道 | 命名隧道（推荐） |
|---|---|---|
| 需要什么 | 什么都不用 | Cloudflare 账号 + 一个托管在 Cloudflare 的域名 |
| 地址 | `xxx.trycloudflare.com`，**每次重启都会变** | 你自己的固定域名 |
| 适合 | 先试试看 | 长期使用、完整版 |

**命名隧道设置：** Cloudflare 控制台 → Zero Trust → Networks → Tunnels → 新建隧道（类型 Cloudflared）→ 复制安装命令里 `--token` 后面那串 → 在「Public Hostname」里添加 `router.example.com`，服务填 `HTTP` / `127.0.0.1:18765`。把 token 和域名填进安装脚本即可。

## 连接 Claude（AI 版）

Claude 网页版或 App：**设置 → 连接器 → 添加自定义连接器**，URL 填安装时打印的「**Claude 连接器地址**」（面板「系统操作 → Claude 连接器地址」里也能复制），不需要填 OAuth。之后在对话里就能直接让 Claude 管理路由器。

连接器地址和登录地址是两把不同的钥匙：连接器地址只给 Claude 用，**打不开面板**；换登录密钥不影响 Claude，泄露了也可以在面板里单独换一个连接器地址。

> 从 v1.3.0 或更早升级的**托管版**：以前在 Claude 里用登录地址加的连接器会提示「要用单独的连接器地址」，把它删掉，用新的连接器地址重新添加就行。自建版用旧的登录地址暂时还能用，也建议换成连接器地址。

Claude 能用的工具包括：路由器状态、设备列表、实时网速、连接列表、OpenClash 节点切换 / 延迟测试 / 模式切换 / 自定义规则、系统日志、服务控制、软件包、uci 读写与回滚、OAF 应用过滤，以及在其他工具做不到时执行 shell 命令。

会断网的操作（改网络/防火墙、重启路由器、重启 OpenClash）在工具说明里都要求 Claude **先说明影响、等你确认**再执行；修改 uci 前会自动备份，可以一键回滚。

## 手机面板

用手机浏览器打开 `https://<你的域名>/panel/`，第一次粘贴登录地址登录（托管版还要输一次登录码），然后「添加到主屏幕」，就和 App 一样用。不用了点侧边栏最下面的「退出登录」。

**首页**（打开面板默认就是这一页，侧边栏最上面）：实时流量曲线（每 2 秒刷新）、今日流量和用得最多的设备、在线设备（无线 / 有线），点卡片直接跳到流量统计、设备页。更详细的系统和 OpenClash 状态在「状态 → 概览」。

**托管版的登录码：** 每台手机第一次打开面板要输一次，输对以后这台手机就不用再输了。登录码在官网账号页拿（这台路由器下面点「获取登录码」，10 分钟有效，用一次就作废），所以要先把路由器**绑定到官网账号**。官网打不开时，在路由器后台终端运行 `cmcp-logincode` 拿一个应急登录码。面板「系统操作 → 已登录的手机」能看到哪些手机能打开面板，不认识的马上移除。

**一键更新：** 有新版本时首页会提示，点「一键更新」，路由器自己下载同一种安装包、校验后装好，设置都保留，不会断网；装完起不来会自动退回原来的版本。也可以在「系统操作 → 检查更新」里手动查。

- 首页：在线状态、实时网速、CPU / 内存、快捷操作
- OpenClash：节点切换与测速、订阅管理、配置文件、覆写、自定义规则、插件设置
- 设备：在线设备、改名、拉黑、暂停上网（到点恢复 / 每天定时断网）
- 流量统计、网速测试（代理 / 直连）、连接列表
- 文件管理、终端、系统日志、进程、LuCI 原版页面（自动登录）
- 断线记录与看门狗、每日体检、云端备份（完整版）、手机通知（完整版）
- 连着家里 Wi-Fi 时，面板自动选「直连」还是「走代理节点」：节点卡了或断了会自动改走直连，不用重启 OpenClash
- 添加新手机（扫码登录）、换登录密钥（旧地址马上作废）、绑定到官网账号（托管版）
- 面板锁：指纹或 4–6 位数字密码，离开 5 分钟自动上锁
- 主题与背景：默认磨砂玻璃风格，可选 8 款预设背景或手机相册里的图片，调模糊和明暗；也能一键换回简洁样式

## 完整版：部署 Cloudflare Worker

完整版的推送、云端备份、断电断网判断由一个 Cloudflare Worker 提供，部署步骤见 [cloud/README.md](cloud/README.md)。大致是：

1. 在路由器上运行 `sh install.sh --full`，它会生成 3 个密钥并打印出来；
2. 在电脑上用 `wrangler` 部署 `cloud/` 目录，把这 3 个密钥和 VAPID 密钥设成 Worker 的 secret；
3. 打开面板「断线记录」页，「云端监测」显示正常就好了。

## 安全说明

请务必读一下：

- **登录地址 = 路由器 root 权限。**（纯面板版也一样：面板里有终端和文件管理） 地址里的密钥（40 位随机字符）能执行任意命令。泄露后请立即换一个：面板「系统操作 → 换登录密钥」，旧地址马上作废；然后其他手机重新添加（自建完整版还要更新 Worker 的 `PANEL_TOKEN`）。
- **托管版多一道登录码。** 光有登录地址还不够，每台手机第一次还要输官网账号里拿的登录码；所以官网账号的密码也要设好，不认识的账号在面板「系统操作 → 绑定到账号」里移除。
- **Claude 连接器地址同样能控制路由器**（通过 Claude 执行命令），也别发给别人；泄露了在「系统操作 → Claude 连接器地址」里换一个。
- **面板锁只防「拿到你手机的人」**，不防拿到登录地址的人。它是浏览器端的保护：清除网站数据会让锁失效（同时也会退出登录，需要重新粘贴地址）。
- 面板里打开的 LuCI 原版页面使用一个专用的 rpcd 账号 `cmcp`（随机密码，保存在 `/etc/claude-mcp/luci_pass`），只有带着面板 Cookie 的请求才能使用。
- 服务只监听 `127.0.0.1:18765`，局域网和公网都无法直接访问，只能经过 Cloudflare 隧道。
- 想多一层保护，可以在 Cloudflare Zero Trust 里给 `/panel/*` 加 Access 登录（注意不要拦住 `/cgi-bin/mcp/*`，否则 Claude 连不上）。

## 常见问题

**Claude 提示连接器连不上？** 先在手机浏览器打开面板地址确认隧道是通的；临时隧道重启后地址会变，需要到 Claude 里更新地址（运行 `grep trycloudflare /tmp/claude-mcp-tunnel.log` 查看新地址）。

**面板显示「连不上路由器」？** 看看 `/etc/init.d/claude-mcp status`，以及 `logread | grep -E 'uhttpd|cloudflared'`。看门狗也会自动重启没响应的面板服务和隧道。

**没装 OpenClash 能用吗？** 能。系统、设备、流量、文件、终端、看门狗等功能不依赖 OpenClash；节点、订阅、规则、分流测速这些 OpenClash 相关功能就用不了。

**侧边栏和 LuCI 后台的菜单不一样？** 侧边栏按用途重新分了组：OpenClash、PassWall 在「代理」里，终端用面板自己的（「工具」里），「服务」里也有这几个的入口。侧边栏会读路由器的真实菜单：没装的插件不显示，新装的插件自动出现在对应的组里。

**连着家里的 Wi-Fi 时面板打不开，换成手机流量就好？** 手机连家里 Wi-Fi 时，打开面板的流量会经过 OpenClash，节点卡了就打不开。面板每 3 分钟会自动检查，代理打不开就改走直连（需要先在面板「拉黑名单」里启用过一次规则集）。急的话先用手机流量打开。

**托管版安装时，邀请码提问一闪而过？** 新版已经修好。旧版可以在安装目录里运行 `sh install.sh --invite 邀请码`。

**配对码过期了？** 在路由器后台终端运行 `cmcp-pair` 再拿一个，或者在面板「系统操作 → 绑定到账号」里拿。

**托管版打开面板要输登录码（第一次、退出登录以后、换手机），去哪拿？** 官网账号页（[yrlove520.com/app](https://yrlove520.com/app)），这台路由器下面点「获取登录码」，再点「打开面板」就自动填好。账号里还没有这台路由器：先用配对码绑定。官网打不开：在**路由器后台的终端**里输入 `cmcp-logincode` 回车，拿一个应急登录码。详细步骤见 [📱 手机教程 · 登录码怎么拿](docs/install-phone.md#登录码怎么拿第一次退出登录以后换手机清了浏览器数据都一样)。

**在面板的「终端」里输 `password` 提示 command not found？** 面板里的终端已经是 root 身份了，不用登录，`password` 不是命令。教程里说的「终端」（安装、升级托管版、拿配对码和应急登录码）指的是**路由器后台的终端**：LuCI「服务 → 终端」或 SSH，登录用户名 `root`、密码是路由器后台密码。安装和升级一定要在后台终端里做，面板终端在安装过程中会断开。

**想自己运营托管服务（给别人发邀请码）？** 见 [cloud/HOSTING.md](cloud/HOSTING.md)，手机上用 GitHub 一键部署就行。

**会不会和 LuCI 冲突？** 不会。面板用的是独立的 uhttpd 实例（只监听 127.0.0.1:18765），不改动原有的 LuCI 和 Web 服务。
