怎么开始（只用手机，5 分钟）

  1. 拿到试用码或邀请码
    注册账号就能领 7 天免费试用码（装好后自动加到你的账号里）；也可以找提供服务的人要邀请码。
  2. 打开路由器后台的终端
    手机连家里 Wi-Fi，浏览器打开路由器后台（比如 http://192.168.1.1）→「服务」→「终端」，用 root 和后台密码登录。没有「终端」可以用手机 SSH 软件。（不是装好以后面板里的那个终端。）
  3. 粘贴这条命令，回车
    装纯面板版就把 hosted-ai 改成 hosted-noai，其他地方别动：
    # ⚠️ hosted-ai = AI 版；纯面板版改成 hosted-noai
cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted-ai.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh
  4. 输入邀请码
    装完会显示一个链接，带着这台路由器的密钥：只在自己手机上打开，别发给别人。屏幕最后是这样的：
    ================ 安装完成 ================

👉 接下来用手机做（10 分钟内）：

  1. 手机打开这个链接：

     https://ab3cd4ef.yrlove520.com/panel/#login=…&pair=…

  2. 页面上点「绑定官网账号」，登录或注册账号
  3. 绑定好后官网会显示登录码，点「打开面板」
  5. 手机打开链接
    面板会提示输入登录码（为了安全，每台手机第一次要输一次），点上面的「绑定官网账号」。
  6. 绑定账号，进面板
    登录或注册官网账号，路由器自动绑定，并自动显示登录码；点「打开面板」就自动填好进去了。之后「添加到主屏幕」，或者装下面的安卓 App。
  7. AI 版：连上 Claude
    把「Claude 连接器地址」填到 Claude 的「设置 → 连接器 → 添加自定义连接器」里。

常见问题

托管网址打不开了，提示被停用、到期或者删除了，怎么恢复？

家里上网和路由器上的设置都不受影响，只是专属网址、推送、云端备份停了。先打开账号页看这台路由器显示的是哪种情况：

  • 已到期暂停：点「续期」输入续期码，或者点「申请续期」填表等审核。续上马上恢复，什么都不用做。暂停超过 30 天会被彻底删除。
  • 已被停用，某日前可恢复：被提供服务的人停用了（可能是误删）。在显示的日期前联系他，他在管理页一键就能恢复，恢复后原来的网址、登录过的手机都照常能用。
  • 账号里已经没有这台路由器（或者收到了「已被彻底删除」的邮件）：要一个新的邀请码，手机连家里 Wi-Fi，打开路由器后台「服务 → 终端」，把安装命令再运行一次，最后的 sh install.sh 改成 sh install.sh --invite 新邀请码。路由器上的设置都保留，网址会换成新的；装完照着屏幕上的链接重新绑定账号就行。

试用快到期了怎么办？

到期前 3 天会推送提醒。在账号页这台路由器下面点「申请续期」填个表，审核通过就自动续上；有续期码的点「续期」输入。不用重装。

换了手机、清了浏览器数据，怎么再登录面板？

打开账号页，在这台路由器下面点「获取登录码」，再点「打开面板」就自动填好了。官网打不开时，在路由器后台终端运行 cmcp-logincode 拿一个应急登录码。

连着家里 Wi-Fi 时面板打不开，换成手机流量就好？

多半是代理插件正在重启或者节点卡了。面板会自动改走直连，稍等一两分钟再刷新；急的话先用手机流量打开。路由器上的「自动任务」里可以看到这些自动处理开没开。

装的不是 OpenClash，能用吗？

能。OpenClash、Nikki、PassWall、PassWall2、HomeProxy、SSR Plus+ 都能自动认出来；装了两个以上的，在面板「概览」里点「代理插件 · 切换」换着用。没装代理插件也能用设备、流量、测速、断线记录这些功能。

遇到问题、想要新功能？

面板侧边栏最下面、首页最下面都有「问题反馈」，可以附截图，直接发给开发者。发完会给一个受理编号，开发者处理到哪一步，在面板侧边栏「帮助 → 我的反馈」、官网账号页，或者这一页上面输入编号都能看到。

安全

登录密钥在你的路由器上生成，保存在路由器和你自己的手机上。
云端备份备份里是路由器的全部设置（包括登录密钥、Wi-Fi 密码、宽带账号）。v2.0.8 起可以开启加密：路由器上有 openssl 的自动加密，没有的在面板「云端备份」页点「开启加密」装一下；开启后备份在路由器上加密后才上传，密钥只在你的路由器上，托管服务只存看不懂的密文。没开启加密的备份仍然原样存在云端。不想用云端备份，可以在「自动任务」里关掉。
新手机新手机要有登录地址（或者用已经能用的手机「添加新手机」扫码），还要输一次登录码。登录码只有绑定了这台路由器的账号才能拿，10 分钟有效、用一次就作废。就算登录地址泄露了，没有登录码也打不开面板。
账号账号记录「你有哪几台路由器」，用来拿登录码。账号里没有密钥，不能直接打开面板。
Claude 连接器AI 版给 Claude 单独一把钥匙，只能给 Claude 用、打不开面板，泄露了可以单独换。
要说明的风险面板的一键更新来自我们在 GitHub 发布的安装包；在外面打开面板的流量经过 Cloudflare 加密转发。这两个环节如果出了问题，理论上会影响到路由器。发现安全问题请用报告表单告诉我们。
更多做了哪些措施、没覆盖的风险、觉得被入侵了怎么办，见安全说明；存了哪些数据、存多久、怎么删，见隐私政策。
不想用了路由器上运行卸载脚本，专属网址自动交还；90 天没上线也会自动回收。

自己搭建

不想用托管服务？也可以用自己的 Cloudflare 账号和域名，或者只在家里局域网用。四个自建版本（AI 版 / 纯面板版 × 精简版 / 完整版）和教程都在 GitHub。开源，MIT 许可证。
