# 安装教程：托管版

> 不用注册 Cloudflare、不用买域名：在官网注册账号、拿个安装码，自动得到一个专属网址，在家在外都能用；手机推送、每天云端备份、断电断网判断全都自带。

托管版有两个版本，**装的时候在终端里选**（输 1 或 2），命令是同一条：

| 版本 | 有什么 | 适合 |
|---|---|---|
| **1) AI 版** | 手机面板 + 能在 Claude 里用中文对话管理路由器 | 想让 AI 帮你切节点、查问题 |
| **2) 纯面板版** | 只有手机面板，不接 AI | 只想在手机上点点 |

## 你需要准备

- 一台 **OpenWrt 22.03 或更新**的路由器（Kwrt、ImmortalWrt 等也可以），并且能上网
- 路由器闪存剩余空间 **40 MB 以上**（登录路由器运行 `df -h /overlay` 看 `Available`）
- 一个**官网账号**（手机打开 [yrlove520.com/app](https://yrlove520.com/app) 用邮箱注册，免费）
- 一部手机就够了；有电脑也可以用电脑装

## 第 1 步：在官网拿安装码和安装命令

1. 手机打开 [yrlove520.com/app](https://yrlove520.com/app)，注册（或登录）官网账号。
2. 在「**添加路由器 → 装新路由器**」里：
   - 新账号点「**领取**」免费试用；或者
   - 有邀请码（找提供托管服务的人要）：填在「有邀请码？填在这里」，点「**兑换**」。
3. 下面会出现一张「**安装码**」卡片，里面有一条**带着安装码的安装命令**，点「**复制命令**」。（AI 版和纯面板版是同一条命令，装的时候再选。）

> 安装码 7 天内有效、只能装一台；没用掉的过期后自动作废（邀请码的名额会退回去）。邀请码不能直接在路由器上用，一定要先在官网兑换成安装码。

## 第 2 步：在路由器上运行安装命令

### 只用手机（推荐）

1. 手机连上家里的 Wi-Fi，浏览器打开路由器后台（比如 `http://192.168.1.1`）→「服务」→「终端」，用 `root` 和后台密码登录。（没有「终端」：用手机 SSH 软件 JuiceSSH / Termius 连 `root@路由器地址`）
2. 粘贴第 1 步复制的命令，回车。它长这样（最后是你的安装码）：
   ```sh
   cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh --invite 你的安装码
   ```
3. **选版本**：
   安装开始后终端会问装哪个版本：

   ```
     装哪个版本？
     1) AI 版：手机面板 + 能在 Claude 里用对话管理路由器
     2) 纯面板版：只有手机面板，自己动手管理，不接 AI
   输入 1 或 2，回车 [1]：
   ```

   - 想在 Claude 里用中文对话管路由器：输 **1**（AI 版）
   - 只要手机面板：输 **2**（纯面板版）
   - 以后想换：再运行一次安装命令选另一个，网址和设置都保留。
4. 选好后等它装完（一两分钟）。

每一步的详细说明见 [📱 手机教程](install-phone.md)。

> ⚠️ 从自建版换成托管版、或者升级托管版时，**不要用路由器面板里的「终端」**：安装中面板的连接会被换掉，面板终端会断开。

### 用电脑

在 [Releases](https://github.com/wznwzn123/openwrt-claude-panel/releases/latest) 下载托管版安装包 **`openwrt-claude-panel-hosted.tar.gz`**，然后在电脑终端（Windows：PowerShell；macOS：终端）运行（`192.168.1.1` 换成你路由器的地址，`你的安装码` 换成官网给的）：

```sh
cd ~/Downloads
scp openwrt-claude-panel-hosted.tar.gz root@192.168.1.1:/tmp/
ssh root@192.168.1.1
cd /tmp && tar xzf openwrt-claude-panel-hosted.tar.gz && cd openwrt-claude-panel
sh install.sh --invite 你的安装码
```

运行后同样会问装 AI 版（输 1）还是纯面板版（输 2）。

> 如果 scp 提示 `sftp-server: not found`，在 scp 后面加 `-O`。

## 第 3 步：回官网点「打开面板」

装完终端会显示：

```
✓ 开通成功：https://ab3cd4ef.yrlove520.com
✓ 路由器已经自动加到你的官网账号里，你是它的主账号
================ 安装完成 ================

✅ 这台路由器已经加到你的官网账号里，你是它的主账号。

👉 接下来：回到手机上的官网「我的路由器」（页面会自动刷新），
   点这台路由器的「打开面板」就进去了，不用输任何码。
```

1. 回到官网，「我的路由器」里自动出现这台路由器（不用刷新），点「**打开面板**」，直接进去，**什么码都不用输**。
2. 添加到主屏幕：安卓（Chrome / Edge）右上角菜单 →「添加到主屏幕」；iPhone（Safari）分享 →「添加到主屏幕」。也可以装[安卓 App](https://yrlove520.com/app/router-panel.apk)。
3. 打开推送：「断线记录」页 →「手机通知」→「开启通知」。建议再打开**面板锁**：「系统操作」→「面板锁」。

**换手机、清了浏览器、退出登录以后：** 在那台手机上登录官网，点「打开面板」就行。

**家里人也要用：** 让他注册自己的官网账号；你在面板「**我的主页 → 家人**」里点「添加家人」，选他能做什么（只看 / 家人 / 几乎全部，或者一项项勾），生成**加入码**发给他。他在官网「添加路由器 → 加入家人」里填上（或者直接点你发的链接），就成了这台路由器的**子账号**，同样从官网打开面板。一台路由器一个主账号、最多 10 个子账号；子账号能做什么、用到哪天、停用还是移除，都由主账号决定。

**官网打不开、急着用：** 在路由器后台终端输入 `cmcp-logincode` 回车，拿一个应急登录码（10 分钟有效、用一次就作废），在面板「官网打不开、急着用？」里输入。

**AI 版：** 把「**Claude 连接器地址**」填到 Claude 的 **设置 → 连接器 → 添加自定义连接器**，就能在对话里管理路由器。忘了地址：面板「我的主页 → 敏感信息」（验证后）的「Claude 连接器地址」。

## 第 4 步：以后升级

面板「概览」页提示有新版时点「**一键更新**」，路由器自己下载安装，设置都保留、不会断网，装不好会自动退回。（v2.0.1 及更早的版本一键更新用不了，要把第 1 步的命令在路由器后台终端里再运行一次，升到 v2.0.2 以后就能一键更新了。）

## 常见问题

**提示「邀请码要先在官网兑换成安装码」？** 邀请码不能直接在路由器上用：在官网「装新路由器」里填邀请码兑换，复制那里给的安装命令再运行。

**安装码提示不对 / 过期了？** 安装码 7 天有效、只能装一台。回官网「装新路由器」重新领或兑换一个。

**邀请码提示不对 / 用完了 / 过期了？** 找提供邀请码的人再要一个。

**提示「名额已满」？** 托管服务的人数到上限了，联系提供服务的人。

**连着家里 Wi-Fi 时面板打不开，换成手机流量就好？** 打开面板的流量经过了 OpenClash 的代理节点，节点卡了就打不开。面板每 3 分钟自动检查，代理打不开会自动改走直连（需要先在面板「不走代理」里启用过一次规则集）。

**会不会被别人进我的路由器？** 面板只能从官网账号里打开：官网点「打开面板」时发一张 2 分钟有效、只能用一次的票，路由器拿它去官网核对是谁、是主账号还是子账号，再给这台手机发钥匙。官网账号在新设备登录要密码加邮箱验证码。就算有人拿到了面板网址，没有你的官网账号也进不来。子账号只能用主账号给他开的功能（路由器上也会检查）。

要说明的是：面板的一键更新来自我们在 GitHub 发布的安装包；在外面打开面板的流量经过 Cloudflare 加密转发。这两个环节如果出了问题，理论上会影响到路由器。

**云端备份存了什么？** 备份里是路由器的全部设置（包括登录密钥、Wi-Fi 密码、宽带账号）。6.0 起一律加密：备份**在路由器上加密后才上传**，密钥只在你的路由器上，托管服务只存看不懂的密文（路由器没有 openssl 也行，用面板自带的加密）。以前没加密就上传的旧备份，升级后下次备份成功时会自动加密后换掉。不想用云端备份，可以在「自动任务」里关掉。

**登录地址泄露了？** 面板「我的主页 → 敏感信息」（验证后）的「换登录密钥」，旧地址马上作废，原版页面的门禁钥匙也一起换；已经登录的手机照常能用。Claude 连接器地址是另一把钥匙，不受影响；它泄露了就在「我的主页 → 敏感信息」里的「Claude 连接器地址」里换一个。

**OpenClash 重启、节点卡住时，面板和 Claude 会跟着断吗？** v2.0.4 起不会：隧道直连 Cloudflare，不经过 OpenClash（v2.0.6 起 Nikki、PassWall、PassWall2、HomeProxy、SSR Plus+ 也一样）。直连连不上时 15 分钟后自动改回走代理，一天后再试。想一直走代理：面板「自动任务」页里关掉「隧道直连 Cloudflare」（v2.0.5 起；或者后台终端运行 `cmcp-tunbypass off`）。

**托管网址打不开，或者收到「托管网址已被删除 / 已停用 / 已到期」的提醒？** 家里上网和路由器设置都不受影响。打开官网账号页看这台路由器的状态：
- 「已到期暂停」：点「续期」输入续期码或「申请续期」，续上马上恢复；暂停超过 30 天会被彻底删除。
- 「已被停用，某日前可恢复」：在那个日期前联系提供服务的人，管理页一键恢复，恢复后什么都不用做。
- 账号里已经没有这台路由器（或收到「已被彻底删除」的邮件）：在官网「装新路由器」里重新拿一个安装码，把那里给的命令在路由器后台终端再运行一次。安装程序会重新开通，设置都保留；网址会换成新的，手机从官网重新打开面板，Claude 连接器换新地址，推送重新开一次。

**升级？** 面板里「一键更新」；或者把安装命令在路由器后台终端里再运行一次，网址和设置都保留，不用新的安装码。

**「终端」是哪个？面板终端里输 `password` 提示 command not found？** 安装、升级、`cmcp-pair`、`cmcp-logincode` 都在**路由器后台的终端**里运行（LuCI「服务 → 终端」或 SSH，用户名 `root`、密码是后台密码）。手机面板里的终端已经是 root，不用登录，`password` 不是命令。

**升级到 5.2 以后面板让我「从官网打开」？** 5.2 起托管版的面板都从官网打开（更安全），以前登录的手机要从官网「我的路由器 → 打开面板」重新进一次，以后就不用了。不认识的手机在面板「我的主页 → 敏感信息 → 登录着的设备」里移除。

**老路由器以前绑了好几个官网账号？** 5.2 起一台路由器只有一个主账号。第一次从官网打开时会让你们选一个当主账号（被选的人收邮箱验证码确认），其他人自动变成子账号（家人权限），以后由主账号管。

**不用了怎么办？** 登录路由器运行 `cmcp-uninstall`（5.0 以前的版本：重新下载解压安装包，在里面运行 `sh uninstall.sh`），专属网址会自动交还。超过 90 天没上线的也会自动回收。

**从自建版换成托管版？** 网址会变成 `xxxxxxxx.yrlove520.com`；每台手机都从官网「打开面板」进去；Claude 连接器要换成新的连接器地址；推送要重新开一次；以前的云端备份留在旧服务上。登录密钥和面板里的设置都保留。
