## v3 → v4（按用户意见重做，见 `docs/spec-v4.md`）

| 用户意见 | v4 怎么改的 |
|---|---|
| 背景音乐不好听，用参考仓库里的音乐 | 换成 video-shotcraft 的 Mixkit tech-house。先测节拍网格（124 BPM，残差 p95 13 ms），再按网格重排全片：每个切点、每条消息、每个版本号都落在拍或半拍上。录音音效用模板里授权有记录的 Mixkit 音效 |
| 重点没讲到 | 四件事各给一段：插件能干什么（六个真实页面，每个两小节）、用中文对话管路由器（两轮演示对话，对应真实工具）、装起来简单占用小（安装脚本原文 + 面板本身约 2 MB + 不需要 Python / Node.js / Docker）、更新快（20 个版本逐个翻过 + 十天提交刻度） |
| 字幕有 AI 味 | 去掉「一根线」「线还在，接着写」「说实话 / 说人话」这类句子和四条原则段。画面上的字只剩功能名、产品名、网址，以及界面和终端里本来就有的字 |

v3 的「停更五天」「急刹」「四条原则」三段都删了。十天的提交刻度保留在「更新」段，用虚线带过那五天。
