怎么开始（只用手机，5 分钟）

  1. 拿到邀请码
    托管服务需要邀请码，找提供服务的人要。
  2. 打开路由器后台的终端
    手机连家里 Wi-Fi，浏览器打开路由器后台（比如 http://192.168.1.1）→「服务」→「终端」，用 root 和后台密码登录。没有「终端」可以用手机 SSH 软件。（不是装好以后面板里的那个终端。）
  3. 粘贴这条命令，回车
    装纯面板版就把 hosted-ai 改成 hosted-noai，其他地方别动：
    # ⚠️ hosted-ai = AI 版；纯面板版改成 hosted-noai
cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted-ai.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh
  4. 输入邀请码
    装完会显示一个链接，带着这台路由器的密钥：只在自己手机上打开，别发给别人。屏幕最后是这样的：
    ================ 安装完成 ================

👉 接下来用手机做（10 分钟内）：

  1. 手机打开这个链接：

     https://ab3cd4ef.yrlove520.com/panel/#login=…&pair=…

  2. 页面上点「绑定官网账号」，登录或注册账号
  3. 绑定好后官网会显示登录码，点「打开面板」
  5. 手机打开链接
    面板会提示输入登录码（为了安全，每台手机第一次要输一次），点上面的「绑定官网账号」。
  6. 绑定账号，进面板
    登录或注册官网账号，路由器自动绑定，并自动显示登录码；点「打开面板」就自动填好进去了。之后「添加到主屏幕」，或者装下面的安卓 App。
  7. AI 版：连上 Claude
    把「Claude 连接器地址」填到 Claude 的「设置 → 连接器 → 添加自定义连接器」里。

每一步的详细说明：📱 手机教程 · 用电脑装：托管版教程

安卓 App

路由器面板 App

扫码、相册识别二维码、粘贴或手动添加路由器，几台一键切换；有新版本打开就提醒。安卓 7.0 以上可用。

下载安卓 App

安装时如果提示「未知来源」，允许一次就行。苹果手机直接用浏览器打开面板，「添加到主屏幕」即可。

安全

登录密钥只在你的路由器和你自己的手机上生成、保存。托管服务拿不到，所以也进不了你的路由器。
新手机新手机要有登录地址（或者用已经能用的手机「添加新手机」扫码），还要输一次登录码。登录码只有绑定了这台路由器的账号才能拿，10 分钟有效、用一次就作废。就算登录地址泄露了，没有登录码也打不开面板。
账号账号记录「你有哪几台路由器」，用来拿登录码。账号本身拿不到密钥，不能直接打开面板。
Claude 连接器AI 版给 Claude 单独一把钥匙，只能给 Claude 用、打不开面板，泄露了可以单独换。
不想用了路由器上运行卸载脚本，专属网址自动交还；90 天没上线也会自动回收。

自己搭建

不想用托管服务？也可以用自己的 Cloudflare 账号和域名，或者只在家里局域网用。四个自建版本（AI 版 / 纯面板版 × 精简版 / 完整版）和教程都在 GitHub。开源，MIT 许可证。
