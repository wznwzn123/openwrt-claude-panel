# OpenWrt AI Panel（路由器面板）

OpenWrt 路由器的**手机控制面板**（PWA，可添加到主屏幕），还可以选择接入 **AI**（Claude、ChatGPT，或者在 Cherry Studio 这类应用里用 DeepSeek、通义千问等），用中文对话管理路由器。

🌐 **官网：[yrlove520.com](https://yrlove520.com)** · 托管版（注册账号就能装，自带专属网址）、账号登录、安卓 App 下载都在这里。

- 手机面板覆盖日常要用的一切：代理插件（OpenClash、Nikki、PassWall、PassWall2、HomeProxy、SSR Plus+ 自动认出）、设备管理、流量统计、测速、断线记录、文件管理、终端……不用再在手机上缩放 LuCI。
- AI 版：在 AI 里说一句「把奈飞切到新加坡节点」「看看谁在占网速」「给这台设备晚上 11 点断网」，它就能直接在路由器上操作。不想用 AI 就装纯面板版。
- 全部跑在路由器自带的 `ucode` + `uhttpd` 上，**不需要 Python / Node / Docker**，占用很小。
- 通过 Cloudflare 隧道访问：**不用公网 IP、不用开端口**。

> ⚠️ 安装后得到的「登录地址」里带着密钥，拿到它就等于拿到路由器的 root 权限。请当作密码保管，不要发给别人、不要截图分享。详见下方「安全说明」。

## 简洁版教程：5 分钟装好（托管版，只用手机）

> 想看每一步的截图和说明：[📱 手机教程（详细版）](docs/install-phone.md)　·　[兼容性和已知问题](docs/compatibility.md)

**你需要：** 一台 OpenWrt 22.03 以上的路由器（Kwrt、ImmortalWrt 都行）、一部手机、一个**官网账号**（[yrlove520.com/app](https://yrlove520.com/app) 用邮箱免费注册）。

1. **在官网拿安装命令**：登录官网，在「添加路由器 → 装新路由器」里领免费试用，或者填邀请码（找提供托管服务的人要）兑换。下面会出现「安装码」卡片，点「复制命令」。
2. **打开路由器的终端**：手机连上家里的 Wi-Fi，浏览器打开路由器后台（比如 `http://192.168.1.1`）→「服务」→「终端」，用 `root` 和路由器密码登录。后台没有「终端」的话，用手机 SSH 软件（JuiceSSH、Termius）连 `root@路由器地址`。
3. **粘贴命令，回车，选版本**：终端问装哪个版本时，输 **1** 是 **AI 版**（手机面板 + 能用 Claude、ChatGPT 等 AI 对话管路由器），输 **2** 是**纯面板版**（只有手机面板，不接 AI），回车，等它装完。安装码已经在命令里，不用再输；装好路由器自动加到你的官网账号里，你就是主账号。
4. **回官网点「打开面板」**：「我的路由器」里会自动出现这台路由器，点「打开面板」就进去了，不用输任何码。之后「添加到主屏幕」（或者装[安卓 App](#安卓-app)）。
5. **AI 版**：在你用的 AI 里添加连接器（比如 Claude → 设置 → 连接器 → 添加自定义连接器），地址填「**AI 连接器地址**」（装完的备用信息里，或者面板「我的主页 → 敏感信息」（验证后）的「AI 连接器地址」）。
6. **开推送**：面板 →「断线记录」→「手机通知」→「开启通知」。

换手机、清了浏览器：在新手机上登录官网，点「打开面板」。家里人也要用：让他注册官网账号，你在面板「我的主页 → 家人」里给他生成加入码，他成为子账号，能做什么由你决定。

> **两个「终端」别弄混：** 安装、`cmcp-logincode` 这些命令要在**路由器后台的终端**里运行（LuCI「服务 → 终端」，或者 SSH），用户名 `root`，密码是路由器后台密码。手机面板里也有个「终端」，那是装好以后在面板里用的，**输入 `password` 之类的登录信息是没用的**。

在官网下载：**[yrlove520.com/app/router-panel.apk](https://yrlove520.com/app/router-panel.apk)**（大陆也能下），或者在 [Releases](../../releases) 下载 `router-panel.apk`。安卓 7.0 以上可用。

## 运行要求

- OpenWrt 22.03 或更新（需要 `ucode`；Kwrt、ImmortalWrt 等衍生版本同样可用）
- 约 2 MB 闪存空间；`cloudflared` 本身约 30 MB，空间不够请先扩容 overlay
- 代理插件：可选。OpenClash 功能最全（节点、订阅、配置文件、覆写、规则、测速分流）；Nikki 能用节点切换、测速、连接、代理模式；PassWall、PassWall2、HomeProxy、SSR Plus+ 能在面板里开关、换节点、测延迟，其他设置点「插件原版页面」
- 装了好几个代理插件：概览里点「代理插件 · 切换」换着用（一次只开一个）
- 「设备暂停上网」目前使用 `iptables`（fw3 或装了 `iptables-nft` 的 fw4）

安装脚本会自动补装缺少的依赖：`ucode ucode-mod-fs ucode-mod-uci uhttpd curl cloudflared`。

## 安装

**只用手机：** 照上面的[简洁版教程](#简洁版教程5-分钟装好托管版只用手机)或[📱 手机教程](docs/install-phone.md)。

**用电脑：** 每个版本都有一步一步的教程：[托管版](docs/install-hosted.md) · [AI 精简](docs/install-ai-lite.md) · [AI 完整](docs/install-ai-full.md) · [纯面板精简](docs/install-noai-lite.md) · [纯面板完整](docs/install-noai-full.md)。简单来说，在 [Releases](https://github.com/wznwzn123/openwrt-claude-panel/releases/latest) 下载 `openwrt-claude-panel.tar.gz`（自建版）或 `openwrt-claude-panel-hosted.tar.gz`（托管版），然后：

```sh
scp openwrt-claude-panel.tar.gz root@192.168.1.1:/tmp/
ssh root@192.168.1.1
cd /tmp && tar xzf openwrt-claude-panel.tar.gz && cd openwrt-claude-panel
sh install.sh
```

运行后在终端里选版本（输 1 或 2）。装完会打印手机面板地址、登录地址，AI 版还会单独打印「AI 连接器地址」。

也可以用参数免交互安装：

```sh
sh install.sh --invite 安装码                # 托管版：官网「装新路由器」给的命令里已经带着
sh install.sh --ai --lite --tunnel-token <隧道token> --domain router.example.com
sh install.sh --no-ai --full --tunnel-token <隧道token> --domain router.example.com --cloud-url https://router.example.com/cloud
```

### 隧道：两种方式

| | 临时隧道 | 命名隧道（推荐） |
|---|---|---|
| 需要什么 | 什么都不用 | Cloudflare 账号 + 一个托管在 Cloudflare 的域名 |
| 地址 | `xxx.trycloudflare.com`，**每次重启都会变** | 你自己的固定域名 |
| 适合 | 先试试看 | 长期使用、完整版 |

**命名隧道设置：** Cloudflare 控制台 → Zero Trust → Networks → Tunnels → 新建隧道（类型 Cloudflared）→ 复制安装命令里 `--token` 后面那串 → 在「Public Hostname」里添加 `router.example.com`，服务填 `HTTP` / `127.0.0.1:18765`。把 token 和域名填进安装脚本即可。

## 连接 AI（AI 版）

「AI 连接器地址」是标准的远程 MCP 连接器（Streamable HTTP，不用登录），支持添加远程 MCP 连接器的 AI 都能接：

- **Claude**（网页版或 App）：**设置 → 连接器 → 添加自定义连接器**
- **ChatGPT**：在 chatgpt.com/plugins 点「+」→ Add custom MCP server，认证选 No authentication（要看套餐和工作区是否允许）
- **Cherry Studio 等支持 MCP 的客户端**（可以接 DeepSeek、通义千问、Kimi 等）：添加 MCP 服务器，类型选 Streamable HTTP

URL 填安装时打印的「**AI 连接器地址**」（面板「我的主页 → 敏感信息」（验证后）的「AI 连接器地址」里也能复制），不需要填 OAuth。之后在对话里就能直接让 Claude 管理路由器。

连接器地址和登录地址是两把不同的钥匙：连接器地址只给 AI 用，**打不开面板**；换登录密钥不影响 AI，泄露了也可以在面板里单独换一个连接器地址。

**危险操作要你在手机上点「允许」（6.0）**：查看状态、换节点、测速照常；重启路由器、改设置、装卸软件、改代理规则、执行会改东西的命令，AI 会先推送到手机，你在面板里点「允许」才执行（只看的命令，比如 `cat`、`logread`、`uci show`，直接执行）。在面板「我的主页 → 敏感信息 → AI 连接器地址」里还能改成「只读」（只能查看）或「完全放开」（跟以前一样）。这样连接器地址万一泄露，别人也做不了危险操作。

> 从 v1.3.0 或更早升级的**托管版**：以前在 Claude 里用登录地址加的连接器会提示「要用单独的连接器地址」，把它删掉，用新的连接器地址重新添加就行。自建版用旧的登录地址暂时还能用，也建议换成连接器地址。

AI 能用的工具包括：路由器状态、设备列表、实时网速、连接列表、OpenClash 节点切换 / 延迟测试 / 模式切换 / 自定义规则、系统日志、服务控制、软件包、uci 读写与回滚、OAF 应用过滤，以及在其他工具做不到时执行 shell 命令。

会断网的操作（改网络/防火墙、重启路由器、重启 OpenClash）在工具说明里都要求 AI **先说明影响、等你确认**再执行；修改 uci 前会自动备份，可以一键回滚。

## 手机面板

自建版：用手机浏览器打开 `https://<你的域名>/panel/`，第一次粘贴登录地址登录；托管版：在官网「我的路由器」点「打开面板」。然后「添加到主屏幕」，就和 App 一样用。不用了点侧边栏最下面的「退出登录」。

**首页**（打开面板默认就是这一页，侧边栏最上面）：实时流量曲线（每 2 秒刷新）、今日流量和用得最多的设备、在线设备（无线 / 有线），点卡片直接跳到流量统计、设备页。更详细的系统和 OpenClash 状态在「状态 → 概览」。

**托管版从官网打开（5.2）：** 面板只能从官网账号里打开：点「打开面板」时官网发一张 2 分钟有效、只能用一次的票，路由器拿它去官网核对是谁，再给这台手机发钥匙。一台路由器一个**主账号**（权限最大）、最多 10 个**子账号**（家里人，各用各的官网账号），子账号能用哪些功能、用到哪天由主账号在「我的主页 → 家人」里决定，路由器上也会检查。官网打不开时，在路由器后台终端运行 `cmcp-logincode` 拿一个应急登录码。面板「我的主页 → 敏感信息 → 登录着的设备」能看到哪些手机能打开面板，不认识的马上移除。

**我的主页（5.2）：** 左上角菜单（电脑上是左边栏）里的头像。名字头像、托管服务到期时间和续期、这台路由器、家人（加入码、权限、停用、移除、转让主账号）、敏感信息（完整邮箱、官网登录着的设备、登录记录，要邮箱验证码才能看，10 分钟后自动锁上）、这台路由器的操作记录、我的反馈。

**一键更新：** 有新版本时首页会提示，点「一键更新」，路由器自己下载同一种安装包、校验后装好，设置都保留，不会断网；装完起不来会自动退回原来的版本。也可以在「系统操作 → 检查更新」里手动查。

- 首页：在线状态、实时网速、CPU / 内存、快捷操作
- OpenClash：节点切换与测速、订阅管理、配置文件、覆写、自定义规则、插件设置
- 设备：在线设备、改名、不走代理、暂停上网（到点恢复 / 每天定时断网）
- 流量统计、网速测试（代理 / 直连）、连接列表
- 文件管理、终端、系统日志、进程、LuCI 原版页面（自动登录）
- 安全和状态提醒（6.0）：有人登录后台或 SSH、公网 IP 变了、温度或负载过高、存储快满都会推送；同一个外网地址 10 分钟内密码错 5 次自动封 1 小时（家里的设备和用面板的手机不会被封）；新设备连上时，推送上能直接点「暂停它上网」
- 完整原版后台（6.0）：在外面也能原样打开路由器后台，跟在家一样输路由器密码登录；输错 5 次锁 15 分钟、每次登录推送、30 分钟没操作自动退出，太弱的密码不让用；家人要有「完全控制」才看得到
- 断线记录与看门狗、每日体检、云端备份（完整版）、手机通知（完整版）
- 连着家里 Wi-Fi 时，面板自动选「直连」还是「走代理节点」：节点卡了或断了会自动改走直连，不用重启 OpenClash
- 添加新手机（扫码登录）、换登录密钥（旧地址马上作废）、我的主页和家人（托管版）
- 面板锁：指纹或 4–6 位数字密码，离开 5 分钟自动上锁；6.0 起密码由路由器核对
- 主题与背景：默认磨砂玻璃风格，可选 8 款预设背景或手机相册里的图片，调模糊和明暗；也能一键换回简洁样式

## 完整版：部署 Cloudflare Worker

完整版的推送、云端备份、断电断网判断由一个 Cloudflare Worker 提供，部署步骤见 [cloud/README.md](cloud/README.md)。大致是：

1. 在路由器上运行 `sh install.sh --full`，它会生成 3 个密钥并打印出来；
2. 在电脑上用 `wrangler` 部署 `cloud/` 目录，把这 3 个密钥和 VAPID 密钥设成 Worker 的 secret；
3. 打开面板「断线记录」页，「云端监测」显示正常就好了。

## 安全说明

请务必读一下：

- **登录地址 = 路由器 root 权限。**（纯面板版也一样：面板里有终端和文件管理） 地址里的密钥（40 位随机字符）能执行任意命令。泄露后请立即换一个：面板「我的主页 → 敏感信息」（验证后）的「换登录密钥」，旧地址马上作废，原版页面的门禁钥匙也一起换；已经登录的手机照常能用（自建完整版还要更新 Worker 的 `PANEL_TOKEN`）。
- **托管版只能从官网账号打开。** 光有登录地址还不够，每台手机都要从官网账号「打开面板」拿钥匙；所以官网账号的密码也要设好（新设备登录还要邮箱验证码）。建议在官网「账号设置 → 两步验证」里开启验证器 App 验证码（6.0）：开了以后新设备登录要输手机上的 6 位数字，密码和邮箱都被人知道了也登不进来；开启时给的 10 个备用恢复码请存好。不认识的家人在面板「我的主页 → 家人」里移除。
- **AI 连接器地址同样能控制路由器**（通过 AI 执行命令），也别发给别人；泄露了在「我的主页 → 敏感信息」里的「AI 连接器地址」里换一个。6.0 起默认「危险操作要确认」：重启、改设置、装卸软件、改规则这些要你在手机上点「允许」才执行，也可以改成「只读」。
- **手机上不存登录密钥（6.0）。** 登录地址只用来给这台手机换一把它自己的钥匙（在「我的主页 → 敏感信息 → 登录着的设备」里能单独移除）；平时每个请求只带 1 小时有效的通行证，钥匙和通行证都不在网址里。手机钥匙每 12 小时自动换新，旧钥匙被人复制去用会被发现：那台手机会被退出并推送提醒。
- **自建版可以开「登录要输路由器后台密码」**（6.0，「我的主页 → 敏感信息」）：开了以后光有登录地址进不来，新手机还要输一次路由器后台（root）密码。
- **面板锁由路由器核对（6.0）**：密码的摘要存在路由器上，手机上不存；清除网站数据、改手机上的设置都绕不过去。只开密码的：每次新打开都要输；开了指纹的：每天至少要输一次密码。累计输错 20 次，路由器会让这台手机退出。面板锁防的是「拿到你手机的人」，不防拿到登录地址的人（那个靠上面的路由器密码）。
- 面板里打开的 LuCI 原版页面使用一个专用的 rpcd 账号 `cmcp`（随机密码，保存在 `/etc/claude-mcp/luci_pass`），只有带着面板门禁钥匙（Cookie）的请求才能使用；换登录密钥、移除手机时门禁钥匙自动换新，旧的马上作废，面板替手机自动登录的原版后台会话也一起退出（6.0）。
- 服务只监听 `127.0.0.1:18765`，局域网和公网都无法直接访问，只能经过 Cloudflare 隧道。
- 想多一层保护，可以在 Cloudflare Zero Trust 里给 `/panel/*` 加 Access 登录（注意不要拦住 `/cgi-bin/mcp/*`，否则 AI 连不上）。

## 升级 / 卸载

```sh
# 升级：面板里「一键更新」最省事（v2.0.2 起；更早的版本先手动升级一次）；或者下载新版解压后再运行一次，密钥和设置保留
sh install.sh

# 卸载：保留 /etc/claude-mcp 里的设置和记录（5.0 起装好后就有这个命令，不用再找安装包）
cmcp-uninstall
# 连设置一起删掉
cmcp-uninstall --purge
```

## 常见问题

**自动做的事情能关掉吗？** 能。面板「自动任务」页里每一项都有开关：隧道断了自动重启、面板卡住自动重启、清缓存、内存不够时重启代理插件、节点挂了自动换、隧道直连、面板线路自动选择、每日体检、新设备提醒、云端自动备份；6.0 起还有：有人登录后台或 SSH 时提醒、自动拉黑试密码的外网地址、公网 IP 变了提醒（默认关）、温度和负载过高提醒、存储快满提醒。

**遇到问题、想要新功能？** 面板「系统操作 → 问题反馈 / 建议」直接写给开发者（托管版直接发送；自建版会打开 GitHub 提问题页）。

**AI 提示连接器连不上？** 先在手机浏览器打开面板地址确认隧道是通的；临时隧道重启后地址会变，需要到 AI 应用里更新地址（运行 `grep trycloudflare /tmp/claude-mcp-tunnel.log` 查看新地址）。

**面板显示「连不上路由器」？** 看看 `/etc/init.d/claude-mcp status`，以及 `logread | grep -E 'uhttpd|cloudflared'`。看门狗也会自动重启没响应的面板服务和隧道。

**没装 OpenClash 能用吗？** 能。系统、设备、文件、终端、看门狗、定时断网等功能不依赖代理插件；装的是 Nikki、PassWall、PassWall2、HomeProxy 或 SSR Plus+ 的，面板会自动认出来，概览里能开关、换节点、测延迟，侧边栏只显示用得上的页面。每台设备的流量统计目前要 OpenClash 或 Nikki。

**侧边栏和 LuCI 后台的菜单不一样？** 侧边栏按用途重新分了组：OpenClash、PassWall 在「代理」里，终端用面板自己的（「工具」里），「服务」里也有这几个的入口。侧边栏会读路由器的真实菜单：没装的插件不显示，新装的插件自动出现在对应的组里。

**连着家里的 Wi-Fi 时面板打不开，换成手机流量就好？** 手机连家里 Wi-Fi 时，打开面板的流量会经过 OpenClash，节点卡了就打不开。面板每 3 分钟会自动检查，代理打不开就改走直连（需要先在面板「不走代理」里启用过一次规则集）。急的话先用手机流量打开。

**提示「邀请码要先在官网兑换成安装码」？** 5.2 起托管版要先在官网注册账号：在「添加路由器 → 装新路由器」里填邀请码兑换，复制那里给的命令运行。

**升级到 5.2 以后面板让我「从官网打开」？** 在官网「我的路由器」点「打开面板」重新进一次就好，以后不用再弄。以前一台路由器绑了好几个账号的，第一次打开时选一个当主账号（被选的人收邮箱验证码确认），其他人变成子账号。官网打不开：在**路由器后台的终端**里输入 `cmcp-logincode` 回车，拿一个应急登录码。

**在面板的「终端」里输 `password` 提示 command not found？** 面板里的终端已经是 root 身份了，不用登录，`password` 不是命令。教程里说的「终端」（安装、升级托管版、拿应急登录码）指的是**路由器后台的终端**：LuCI「服务 → 终端」或 SSH，登录用户名 `root`、密码是路由器后台密码。安装和升级一定要在后台终端里做，面板终端在安装过程中会断开。

**怎么试用托管版？** 在官网注册账号，「添加路由器 → 装新路由器」里点「领取」免费试用，复制安装命令到路由器「服务 → 终端」里运行，装好后路由器自动加到你的账号里。

**网址被删了怎么恢复？** 看官网「常见问题」里的「托管网址被删除了，怎么恢复」。

**托管服务到期了 / 快到期了？** 用试用或有期限的邀请码开通的路由器有到期时间，官网账号页会显示还剩几天，到期前 3 天推送提醒。找提供服务的人要**续期码**，在官网账号页这台路由器下面点「续期」输入就行；已经到期暂停的，输入后马上恢复（家里上网和路由器设置一直不受影响）。

**想自己运营托管服务（给别人发邀请码）？** 见 [cloud/HOSTING.md](cloud/HOSTING.md)，手机上用 GitHub 一键部署就行。

**会不会和 LuCI 冲突？** 不会。面板用的是独立的 uhttpd 实例（只监听 127.0.0.1:18765），不改动原有的 LuCI 和 Web 服务。
