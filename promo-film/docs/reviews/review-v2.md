## 2. 必须修复（Critical）

1. **「代理」上屏（违反 spec §0 和大陆发布底线）**
   - 10.8–14.5 s：面板顶栏写着「OpenWrt 演示路由器 · 没装代理插件」（证据 /tmp/review2/crop_hdr.png）。
   - 53.6–58 s：自动任务页底部写着「这台路由器没装代理插件，跟代理插件有关的几项不显示。」（/tmp/review2/crop_auto_note.png）。
   - 同一页还有「隧道断了自动重启 / 连不上 Cloudflare」，属于容易被联想的词。
2. **读起来像产品自曝安全问题（63–67 s）**：把「别人进不了你的路由器。」划掉，再接「远程转发…各有哪些风险」和「无法修复」，观众会读成「别人能进你的路由器，而且修不了」。
3. **绝对化用语，且和原则 03 自相矛盾**：更新卡截图里的「不会断网」出现在 11–19 s 和 58–62 s。
4. **第二处冲击（第 1494 帧）失效**：滚动在约第 1484–1486 帧就已经看着停住了；第 1494 帧前后帧差只有 1.1，这一帧画面上什么都没发生。
5. **风险待确认**：
   - 「托管版 / 有邀请码就有专属网址」「新注册送 7 天试用」，等于在宣传一个面向公众的转发服务，涉及备案和广告法。
   - 「用中文对话来管理」加上品牌名里的 Claude，涉及生成式 AI 备案。
   - 片尾的 yrlove520.com 要确认有没有 ICP 备案。
   - 51 s 的反馈卡日期「11/6 21:30」和「11.02–11.06 停更」的叙事、以及「我的反馈」11.09 才上线的事实冲突。
   - 同一张卡里的「能不能想想办法?」用了半角问号。
