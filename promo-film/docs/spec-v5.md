# v5 设计说明：商业级 3D 产品片

用户对 v4 的意见是「效果不惊艳」，要求按商业级视频来做，由导演全权决定。

v5 保留 v4 的内容骨架：配乐、节拍网格、讲的四件事、少字。画面语言整个换成 3D 产品片：
- 主角是一台按产品图标造出来的 3D 路由器；
- 真实界面装在 3D 设备屏幕里，或者漂在 3D 空间里；
- 版本史变成一条可以飞过去的 3D 时间轴。

大陆发布口径不变（见 `spec.md` §0）。界面截图和演示数据跟 v4 相同。

## 技术

- **3D**：three.js，经 `@remotion/three`、`@react-three/fiber`、`@react-three/drei`、`@react-three/postprocessing` 接入。
  - 环境光：程序化的 RoomEnvironment，不依赖外部 HDR。
  - 轮廓光：品牌紫 #6a4dff、青 #00c2d8。
  - 后期：泛光 + 暗角。
- **地面**：模型沿地面镜像一份，上面盖半透明地面，形成倒影（软件 GL 下 MeshReflectorMaterial 出不来）。地面用径向透明度渐隐，融进后面的极光。
- **背景**：3D 画布透明，后面是 mg-styles-15 的 WebGL 极光。定版的液态玻璃透镜也在这一层。
- **预加载**：`@remotion/three` 的画布只在帧变化时重画。纹理和版本标签都在画布挂载前预加载（`src/v5/three/preload.ts`），不会出现「这一帧还没贴上图」。

## 分镜（时间同 v4，钉在 124 BPM 的节拍网格上）

| 小节 | 画面 |
|---|---|
| 0–2 | 黑场。镜头从侧面低角度贴着路由器正面移动，第一颗灯随强拍亮起，一道光扫过机身 |
| 2–4 | 拉开、升高，两道信号弧被画出来，3D 路由器就是产品图标的样子；片名在下方 |
| 4–6 | 笔记本和手机从两侧滑进来，屏幕上是真实面板；两道光流从路由器连到两台设备，光点按拍子跑 |
| 6–8 | 镜头一路推进笔记本屏幕，第 8 小节落鼓时屏幕占满画面 |
| 8–19 | 3D 界面空间：六块真实界面漂在空中，后面是整页界面的淡影和浮尘。镜头每两小节一站，换站在强拍上甩过去（带侧倾）；第 3 拍发光描边圈出重点 |
| 20–27 | 对话框在左，路由器特写在右。调用工具时灯闪；「把访客 Wi-Fi 关了」确认、改完以后，外圈信号弧闪一下熄灭 |
| 28–31 | 终端在左逐拍出现安装步骤，右边路由器每完成一步亮一分，「安装完成」时信号弧画出来；然后镜头摇开，右边给「面板本身约 2 MB / 不需要 …」 |
| 32–35 | 3D 时间轴：十天铺在纵深方向，镜头贴着轴飞，走过的提交小柱亮起，当前版本号立在播放头上方；11.02–11.06 是虚线。第 34 小节第 2 拍镜头升起俯看整条十天，下面出 10 天 · 20 个版本 · 94 次提交 |
| 35.5–40 | 3D 层淡出，液态玻璃透镜滑入，第 36 小节强拍真实图标亮起，停靠定版 |

## 声音

和 v4 相同（`audio/score4.py`，`CUES=out/cues5.json OUT=film5`）。新增的音效点：
- 光扫过机身；
- 两台设备滑入；
- 光流连线；
- 信号弧熄灭；
- 俯看时三个数字的时间。
