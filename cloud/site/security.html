安全说明

我们做了下面这些措施，发现问题会持续修；没覆盖的风险也写在这里。支持哪些系统、测过哪些、已知问题见兼容性和已知问题。最后更新：2026 年 11 月 7 日

做了哪些措施

  • 登录密钥在路由器上生成，保存在路由器和你自己的手机上；官网账号里没有密钥。
  • 新手机要登录码（托管版）：只有绑定了这台路由器的账号能拿，10 分钟有效、用一次作废；输错 10 次锁 10 分钟。
  • 官网登录限次：密码输错、验证码、注册都有次数限制。
  • 登录过的设备：账号页能看到哪些设备登录着你的账号，可以单独退出或一键退出其他所有设备；有新设备登录会发邮件提醒；改密码时其他设备自动退出。
  • 随时换钥匙：面板「系统操作」里能换登录密钥，旧地址马上作废；Claude 连接器是单独一把钥匙，可以单独换。
  • 安装包和更新：一键更新下载后先核对 SHA256，不对就不装。每次发布都附一份依赖清单（SBOM）；代码每次更新都自动扫一遍有没有泄露的密钥、用到的组件有没有已知漏洞。
  • 卸载干净：卸载后逐项检查有没有留下东西，结果存一份记录。
  • 云端备份可以加密（v2.0.8 起）：开启后在路由器上加密再上传，密钥只在路由器上；下载、还原时先校验，被改过的不会使用。
  • 官网页面：不能被别的网站嵌入，不加载外部脚本；没有广告、统计、跟踪代码。

没覆盖的风险

  1. 更新来自 GitHub：一键更新装的是我们在 GitHub 发布的安装包，目前只核对文件完整，没有签名。发布账号如果被盗，可能推送有问题的更新。
  2. Cloudflare 能看到流量：在外面打开面板时，流量经 Cloudflare 加密转发，Cloudflare 那一层能看到内容。
  3. 登录地址和官网账号同时泄露：别人就能拿登录码打开面板。面板能执行命令，打开面板就等于拿到路由器的最高权限，所以登录地址请当密码保管，不要截图分享。
  4. 没开启加密的云端备份：里面的 Wi-Fi 密码、登录密钥等原样存在云端。
  5. 推送内容：微信推送（PushPlus）是明文；「新设备提醒」带设备名、IP 和 MAC 地址。
  6. 不在这个项目范围内的：OpenWrt 系统本身、其他插件、路由器后台（LuCI）和 SSH 的安全。面板不会替你打开这些的公网访问。

觉得被别人动过了，怎么办

  1. 面板「系统操作 → 换登录密钥」，所有旧地址马上作废，再用自己的手机重新添加。
  2. 用 AI 版的：同一页换「Claude 连接器地址」。
  3. 官网账号页「登录过的设备」里把不认识的退出（或者一键退出其他所有设备），再改密码；不放心就注销账号重新注册。
  4. 改路由器的 root 密码和 Wi-Fi 密码（路由器后台「系统 → 管理权」「网络 → 无线」）。
  5. 面板「云端备份」里删掉不放心的备份。
  6. 还是不放心：在路由器上运行卸载脚本（sh uninstall.sh），专属网址和云端数据马上删除。
