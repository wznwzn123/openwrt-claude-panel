# 📱 手机教程：只用手机安装（不需要电脑）

从头到尾只用一部手机，大约 5–10 分钟。下面以**托管版**为例（在官网注册账号就能装，最省事）；自建版的不同之处在每一步里单独说明。

---

## 准备

| 要什么 | 说明 |
|---|---|
| 路由器 | OpenWrt **22.03 或更新**（Kwrt、ImmortalWrt 等都可以），能正常上网 |
| 空间 | 路由器闪存剩余 **40 MB 以上**，压缩闪存（UBIFS、JFFS2，大多数家用路由器）**22 MB 以上**（在终端运行 `df -h /overlay` 看 `Available`） |
| 手机 | 安卓或苹果都行，**连着这台路由器的 Wi-Fi** |
| 路由器后台密码 | 就是平时登录路由器后台（LuCI）的密码 |
| 官网账号 | **托管版**要先在 [yrlove520.com/app](https://yrlove520.com/app) 注册（邮箱 + 密码），能收验证码的邮箱就行。自建版不需要 |
| 邀请码 | 托管版可选：有的话在官网兑换成安装码；没有就领免费试用。自建版不需要 |

## 第 0 步：选版本、拿安装命令

**托管版**（推荐）：

1. 手机打开 [yrlove520.com/app](https://yrlove520.com/app)，注册（或登录）官网账号。
2. 在「**添加路由器 → 装新路由器**」里点「领取」免费试用；有邀请码的，填在「有邀请码？填在这里」点「兑换」。
3. 下面出现「**安装码**」卡片，点「**复制命令**」。命令里已经带着你的安装码。

托管版有两个版本，**装的时候在终端里输 1 或 2 选**（第 3 步），命令是同一条：

| 输入 | 版本 | 有什么 |
|---|---|---|
| **1** | AI 版 | 手机面板 + 能用 Claude、ChatGPT 等 AI 中文对话管理路由器 |
| **2** | 纯面板版 | 只有手机面板，自己动手管理，不接 AI |

> 安装码 7 天内有效、只能装一台。邀请码不能直接在路由器上用，一定要先在官网兑换。

**自建版**（用自己的 Cloudflare，不用官网账号）：也只有一条命令（第 2 步），装的时候在终端里回答两个问题：

| 先问 | 输入 1 | 输入 2 |
|---|---|---|
| 装 AI 版还是纯面板版 | **AI 版**：手机面板 + 能用 Claude、ChatGPT 等 AI 对话管路由器 | **纯面板版**：只有手机面板，不接 AI |
| 装精简版还是完整版 | **精简版**：手机面板 + 本地看门狗，不需要 Cloudflare 账号 | **完整版**：再加推送、云端备份、断电断网判断，要自己的 Cloudflare 和域名、先部署 Worker |

拿不准：托管版选 **2（纯面板版）** 最简单；自建版先选 **2 → 1**（纯面板版 · 精简版）试试。以后想换，再运行一次安装命令选别的，设置都保留。

## 第 1 步：打开路由器的终端

### 方法 A：路由器后台自带的「终端」（推荐）

1. 手机浏览器打开路由器后台，地址一般是 `http://192.168.1.1`（有的是 `10.0.0.1`、`192.168.100.1`，看路由器背面或者手机 Wi-Fi 详情里的「网关」）。
2. 用后台密码登录。
3. 点左上角的菜单 →「**服务**」→「**终端**」。
4. 终端里用户名填 `root`，密码填路由器后台密码。看到下面这样的提示符，就是登录好了：
   ```
   root@OpenWrt:~#
   ```

### 方法 B：后台没有「终端」

- 有 iStore 的：在 iStore 里搜「终端」装上（就是 `luci-app-ttyd`），再按方法 A 打开。
- 或者在手机上装一个 SSH 软件（安卓：JuiceSSH、Termius；苹果：Termius），新建连接：地址填路由器地址，端口 `22`，用户名 `root`，密码填后台密码。

> ⚠️ **装托管版、或者从自建版换成托管版时，不要用路由器面板里的「终端」**：安装过程中面板的连接会被换掉，面板里的终端会中途断开。用上面两种方法之一。

## 第 2 步：粘贴安装命令

**托管版**：把第 0 步在官网复制的命令，在终端里**长按 → 粘贴**，然后回车。它长这样（最后是你的安装码）：

```sh
cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh --invite 你的安装码
```

**自建版**：复制下面这一整行，粘贴回车（**不用改任何地方**，版本在下一步选）：

```sh
cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh
```

粘贴后会先下载（几秒钟），然后看到：

```
==> 安装 AI版·托管版
 ✓ 依赖齐全
==> 复制文件
 ✓ 文件已就位
==> 生成密钥
 ✓ 密钥已就绪
==> 向托管服务申请专属网址
 ✓ 开通成功：https://xxxxxxxx.yrlove520.com
 ✓ 路由器已经自动加到你的官网账号里，你是它的主账号
```

> 下载失败（提示 `wget: not found` 或者 SSL 错误）：把命令里的 `wget -O p.tar.gz` 换成 `curl -fL -o p.tar.gz` 再试。

## 第 3 步：安装中途的提问

**托管版**：只问一个问题，选版本：

```
  装哪个版本？
  1) AI 版：手机面板 + 能用 Claude、ChatGPT 等 AI 对话管理路由器
  2) 纯面板版：只有手机面板，自己动手管理，不接 AI
输入 1 或 2，回车 [1]：
```

想用 AI 中文对话管路由器就输 **1**；只要手机面板就输 **2**；直接回车是 1。以后想换，再运行一次安装命令选另一个，网址和设置都保留。安装码命令里已经带着，不用再输。

- 提示「邀请码要先在官网兑换成安装码」：你粘贴的是邀请码，回官网兑换，复制那里给的命令。
- 提示「安装码不对 / 已经过期」：安装码 7 天有效、只能装一台，回官网重新领或兑换一个。
- 提示「名额已满」：找提供服务的人。

**自建版**：先问两个问题（输 1 或 2 回车），对照第 0 步的表：

```
  装哪个版本？
  1) AI 版：手机面板 + 能用 Claude、ChatGPT 等 AI 对话管理路由器
  2) 纯面板版：只有手机面板，自己动手管理，不接 AI
输入 1 或 2，回车 [1]：

  装精简版还是完整版？
  1) 精简版：手机面板 + 本地看门狗（不需要 Cloudflare 账号）
  2) 完整版：再加 Cloudflare 云端（手机/微信推送、云端备份、断电断网判断，需要先部署 Worker）
输入 1 或 2，回车 [1]：
```

然后问隧道 token 和域名：精简版直接回车可以先用临时隧道；用自己的域名照[自建版教程](../README.md#选哪个版本)里的说明填。

## 第 4 步：回官网点「打开面板」

托管版装好后屏幕最后会显示：

```
================ 安装完成 ================
已安装：AI版·托管版

✅ 这台路由器已经加到你的官网账号里，你是它的主账号。

👉 接下来：回到手机上的官网「我的路由器」（页面会自动刷新），
   点这台路由器的「打开面板」就进去了，不用输任何码。
```

回到官网（第 0 步那个页面），「我的路由器」里会自动出现这台路由器，点「**打开面板**」就进去了。进去以后默认是「**概览**」：实时网速、今日流量、在线设备一眼就能看到。左上角菜单里的头像是「**我的主页**」：托管服务到期时间、家里人（子账号）、操作记录都在那里。

- **AI 版**要用「AI 连接器地址」（第 7 步）：装完的「备用信息」里有，忘了也没关系，面板「我的主页 → 敏感信息」（验证后）的「AI 连接器地址」随时能看。
- 官网打不开、急着用：在路由器后台终端运行 `cmcp-logincode`，拿一个应急登录码（10 分钟有效），在面板「官网打不开、急着用？」里输入。

> **自建版**装完显示的是「手机面板 / 登录地址 / 自动登录链接」：打开自动登录链接就直接进面板。⚠️ 这些地址带着密钥，谁拿到都能控制你的路由器：不要发给别人，不要截图分享；泄露了就在面板「我的主页 → 敏感信息」（验证后）的「换登录密钥」。

## 第 5 步：以后怎么打开

- **托管版**：任何手机（换了手机、清了浏览器、退出登录以后都一样）登录官网，在「我的路由器」点「**打开面板**」。官网账号在新手机上登录要密码 + 邮箱验证码；开了两步验证（6.0，官网「账号设置」里开）的，是密码 + 验证器 App 上的 6 位数字，手机丢了用开启时存的备用恢复码。
- **应急登录码**（官网打不开时）：在**路由器后台的终端**（路由器后台 →「服务」→「终端」，用户名 `root`、密码是后台密码；或者 SSH）里输入 `cmcp-logincode` 回车，会显示一个 8 位应急登录码，10 分钟内有效、只能用一次，输进面板「官网打不开、急着用？」里就行。
- **自建版**：退出登录后重新粘贴登录地址就能进。

## 第 6 步：添加到主屏幕

- 安卓 Chrome / Edge：右上角菜单 →「添加到主屏幕」（Edge 叫「添加到手机」）
- 苹果 Safari：底部「分享」→「添加到主屏幕」
- 想用安卓 App：在 [yrlove520.com](https://yrlove520.com) 下载 App（安装时提示「未知来源」允许一次就行）。托管版：点 App 里的「官网账号（我的路由器）」，登录后点「打开面板」；自建版：点「粘贴」，或者把登录地址填到「手动添加」框里。

> 以前用过面板（比如从自建版换成托管版）：网址变了，主屏幕上旧的图标删掉，重新添加一次。

## 第 7 步（AI 版）：在 AI 里添加连接器

1. 打开你用的 AI 应用添加连接器：Claude（App 或网页）→「设置」→「连接器」→「**添加自定义连接器**」；ChatGPT、Cherry Studio 等见常见问题「能接哪些 AI」。
2. 名字随便填（比如「路由器」），地址填第 4 步的「**AI 连接器地址**」（不是登录地址），保存。
3. 新开一个对话，试试：「看看路由器现在的状态」。

忘了连接器地址：面板「我的主页 → 敏感信息」（验证后）的「AI 连接器地址」里能复制。

> 以前用「登录地址」加过连接器（v1.3.0 及更早）：托管版现在不能用了，把旧的删掉，用连接器地址重新添加。

## 第 8 步：开推送

面板 →「断线记录」→「手机通知」→「开启通知」，浏览器问要不要允许通知时点「允许」。断网、断电、隧道断开、新手机登录面板时会推送到手机。

## 第 9 步：家里其他人

- **你自己的另一部手机**：登录官网，点「打开面板」就行。
- **家里人**（托管版）：让他注册自己的官网账号。你在面板「**我的主页 → 家人**」里点「添加家人」，选他能做什么（只看 / 家人 / 几乎全部，也能一项项勾，还能设用到哪天），生成**加入码**（24 小时有效，只能用一次）发给他。他点你发的链接，或者在官网「添加路由器 → 加入家人」里填加入码，确认后就是这台路由器的**子账号**，同样从官网打开面板。一台路由器一个主账号、最多 10 个子账号；改权限、停用、移除、把主账号转给他，都在「我的主页 → 家人」里（要收一次邮箱验证码确认是你本人）。
- **自建版**：在已经登录的手机上「系统操作 → **添加新手机**」→ 用新手机的相机扫二维码。

不用了、或者手机要给别人：面板侧边栏最下面「**退出登录**」。不认识的手机：「系统操作 → **已登录的手机**」里移除。

## 以后升级

有新版本时，面板「概览」页会提示「路由器有新版本」，点「**一键更新**」就行：路由器自己下载、校验、安装，设置都保留，不会断网，面板断开十几秒后自动回来；装不好会自动退回原来的版本。

> v2.0.1 及更早的版本一键更新用不了，要在路由器后台终端里把第 2 步的命令再运行一次（托管版不用新的安装码），以后就能一键更新了。

## 常见问题

**升级到 5.2 以后，面板让我「从官网打开」？**
5.2 起托管版的面板都从官网打开（更安全）。以前登录过的手机要在官网「我的路由器」点「打开面板」重新进一次，以后就不用了。

**老路由器以前绑了好几个官网账号？**
5.2 起一台路由器只有一个主账号。第一次从官网打开时会让你们选一个当主账号（被选的人收邮箱验证码确认），其他人自动变成子账号（家人权限），以后由主账号管。

**连着家里的 Wi-Fi 时面板打不开，换成手机流量就好？**
连家里 Wi-Fi 时，打开面板的流量会经过 OpenClash 的代理节点，节点卡了就打不开。面板每 3 分钟自动检查，代理打不开会自动改走直连（需要先在面板「不走代理」里启用过一次规则集）。急的话先用手机流量打开。

**OpenClash 重启、节点卡住时，面板和 AI 会跟着断吗？**
v2.0.4 起不会了：安装时会把路由器连 Cloudflare 的隧道改成直连，不经过 OpenClash（不用重启 OpenClash，也不影响家里其他设备）。v2.0.6 起 Nikki、PassWall、PassWall2、HomeProxy、SSR Plus+ 也一样（Nikki 要等它下次重启才生效）。如果你那里直连 Cloudflare 连不上，路由器会在 15 分钟后自动改回走代理，一天后再试一次。想一直走代理：在面板「自动任务」页里关掉「隧道直连 Cloudflare」（v2.0.5 起；也可以在路由器后台终端运行 `cmcp-tunbypass off`）。

**托管网址打不开，或者收到「托管网址已被删除 / 已停用 / 已到期」的提醒？**
家里上网和路由器上的设置都不受影响，只是专属网址、推送、云端备份停了。先打开官网账号页看这台路由器显示的是哪种情况：
- **已到期暂停**：在这台路由器下面点「续期」输入续期码，或者「申请续期」等审核，续上后马上恢复，什么都不用做。暂停超过 30 天会被彻底删除。
- **已被停用，某日前可恢复**：被提供服务的人停用了（可能是误删），在显示的日期前联系他，他在管理页一键就能恢复。恢复后原来的网址、登录过的手机、AI 连接器都照常能用。
- **账号里已经没有这台路由器**（或者收到了「已被彻底删除」的邮件）：在官网「装新路由器」里重新领一个安装码（或者找提供服务的人要邀请码兑换），把那里给的命令在路由器后台终端再运行一次。安装程序会认出原来的网址已经被删除，自动重新开通，路由器上的设置都保留；网址会换成新的，手机从官网重新打开面板，AI 连接器换新地址，推送重新开一次。

**「终端」到底是哪个？在面板终端里输 `password` 提示 command not found？**
有两个终端：
- **路由器后台的终端**：浏览器打开路由器后台（`http://192.168.1.1`）→「服务」→「终端」，用户名 `root`，密码是后台密码；或者用 SSH。**安装、升级托管版、`cmcp-logincode` 都在这里运行。**
- **手机面板里的终端**：装好以后面板「工具 → 终端」。它已经是 root 身份，不用登录，`password` 不是命令，所以提示 not found。平时查东西可以用它，但安装和升级不要在这里做（安装中途面板会断开）。

**提示空间不够？**
终端运行 `df -h /overlay` 看剩余空间，不到 40 MB（压缩闪存 22 MB）的话先清理或扩容；内存够的路由器会自动用「小闪存模式」。

**升级到新版？**
面板「概览」页提示有新版时点「一键更新」（v2.0.2 起）。也可以把第 2 步的命令在路由器后台终端里再运行一次，托管版不用新的安装码，网址、密钥和设置都保留。

**卸载？**
```sh
cmcp-uninstall
```
5.0 起装好就有这个命令。更早的版本提示找不到命令的话，先把第 2 步命令里 `&& sh install.sh` 之前的部分运行一次（重新下载解压），再运行 `sh uninstall.sh`。托管版卸载时专属网址会自动交还。

**从自建版换成托管版要注意什么？**
网址会变成 `xxxxxxxx.yrlove520.com`；手机都从官网「打开面板」进去；AI 连接器要换成新的连接器地址；推送要重新开一次；以前的云端备份留在旧的服务上，新的备份从装好开始算。登录密钥和面板里的设置都保留。
