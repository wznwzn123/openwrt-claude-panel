5 分钟完成安装。全程使用手机，只需一条命令。

  1. 注册账号，获取安装命令

    注册账号后在「添加路由器 → 装新路由器」里领 7 天免费试用（有邀请码的填进去兑换），下面会给你一条带着安装码的命令，点「复制命令」。

    手机连家里 Wi-Fi，浏览器打开路由器后台（比如 http://192.168.1.1）→「服务」→「终端」，用 root 和后台密码登录。没有「终端」可以用手机 SSH 软件。（这里用的是路由器后台自带的终端。）

只记录你名下的路由器，用于获取登录码。账号里没有密钥。

云端备份

备份里是路由器的全部设置（包括登录密钥、Wi-Fi 密码、宽带账号）。开启加密后，备份在路由器上加密后才上传，密钥只在你的路由器上；未加密的备份按原样保存在云端。可在「自动任务」中关闭备份。

Claude 连接器

AI 版为 Claude 单独配一把密钥，仅限 Claude 使用，无法打开面板，泄露后可单独更换。

安装包签名

每次发布都用开发者的密钥签名，一键更新先验证签名，再安装。下载中转站被篡改时，签名校验不通过，路由器不会安装。

已知风险

一键更新安装的是在 GitHub 发布并签名的安装包；远程打开面板的流量经 Cloudflare 加密转发。这两个环节出现问题，可能影响路由器。发现安全问题，请通过报告表单告诉我们。

停用与卸载

运行卸载脚本后，专属网址自动释放；连续 90 天未上线，也会自动回收。

常见问题。大多数情况无需重装。

反馈过问题？查处理进度

输入上报时拿到的 8 位受理编号，无需登录。登录账号后，可在账号页查看自己的全部反馈。

托管网址打不开了，提示被停用、到期或者删除了，怎么恢复？

家里上网和路由器上的设置都不受影响，只是专属网址、推送、云端备份停了。先打开账号页看这台路由器显示的是哪种情况：

  • 已到期暂停：点「续期」输入续期码，或者点「申请续期」填表等审核。续上马上恢复。暂停超过 30 天会被彻底删除。
  • 已被停用，某日前可恢复：在显示的日期前联系提供服务的人，他在管理页一键就能恢复，原来的网址、登录过的手机照常能用。
  • 账号里已经没有这台路由器（或收到「已被彻底删除」的邮件）：在账号页「装新路由器」里重新领一个安装码（或用新的邀请码兑换），复制那里的命令再运行一次。设置都保留，网址会换成新的。

试用快到期了怎么办？

到期前 3 天会推送提醒。在账号页这台路由器下面点「申请续期」填个表，审核通过就自动续上；有续期码的点「续期」输入。不用重装。

换了手机、清了浏览器数据，怎么再登录面板？

在新手机上登录账号页，在「我的路由器」点「打开面板」就进去了，不用输码。官网打不开时，在路由器后台终端运行 cmcp-logincode 拿一个应急登录码。

连着家里 Wi-Fi 时面板打不开，换成手机流量就好？

多半是代理插件正在重启或者节点卡了。面板会自动改走直连，稍等一两分钟再刷新；急的话先用手机流量打开。

用的是其他代理插件，能用吗？

能。OpenClash、Nikki、PassWall、PassWall2、HomeProxy、SSR Plus+ 都能自动认出来；装了两个以上的，在面板「概览」里点「代理插件 · 切换」换着用。未安装代理插件时，设备、流量、测速、断线记录照常可用。

遇到问题、想要新功能？

面板侧边栏最下面、首页最下面都有「问题反馈」，可以附截图，直接发给开发者。发完会给一个受理编号，处理到哪一步，在面板「帮助 → 我的反馈」、官网账号页，或者上面输入编号都能看到。

不想用托管服务？

可以用自己的 Cloudflare 账号和域名，或者只在家里局域网用。四个自建版本和教程都在 GitHub。
