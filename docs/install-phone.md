# 📱 手机教程：只用手机安装（不需要电脑）

从头到尾只用一部手机，大约 5–10 分钟。下面以**托管版**为例（有邀请码，最省事）；自建版的不同之处在每一步里单独说明。

---

## 准备

| 要什么 | 说明 |
|---|---|
| 路由器 | OpenWrt **22.03 或更新**（Kwrt、ImmortalWrt 等都可以），能正常上网 |
| 空间 | 路由器闪存剩余 **40 MB 以上**（装好后在终端运行 `df -h /overlay` 看 `Available`） |
| 手机 | 安卓或苹果都行，**连着这台路由器的 Wi-Fi** |
| 路由器后台密码 | 就是平时登录路由器后台（LuCI）的密码 |
| 邀请码 | **托管版**才要，找提供托管服务的人要。自建版不需要 |
| 邮箱 | **托管版**要注册官网账号（拿登录码用），能收验证码的邮箱就行 |

## 第 0 步：选版本

安装命令只有一条，里面有一个**版本代号**决定装哪个版本：

| 版本 | 代号 | 适合 |
|---|---|---|
| 托管版 · AI 版 | `hosted-ai` | 有邀请码，想在 Claude 里用对话管路由器 |
| 托管版 · 纯面板版 | `hosted-noai` | 有邀请码，只要手机面板 |
| 自建版 · AI 版 · 完整版 | `ai-full` | 用自己的 Cloudflare 和域名，要推送和云端备份 |
| 自建版 · AI 版 · 精简版 | `ai-lite` | 用自己的 Cloudflare，先试试 |
| 自建版 · 纯面板版 · 完整版 | `noai-full` | 不用 AI，要推送和云端备份 |
| 自建版 · 纯面板版 · 精简版 | `noai-lite` | 不用 AI，在手机上点点就行 |

拿不准：有邀请码就选 `hosted-noai`（以后想用 AI，换成 `hosted-ai` 再装一次就行，网址和设置都保留）。

## 第 1 步：打开路由器的终端

### 方法 A：路由器后台自带的「终端」（推荐）

1. 手机浏览器打开路由器后台，地址一般是 `http://192.168.1.1`（有的是 `10.0.0.1`、`192.168.100.1`，看路由器背面或者手机 Wi-Fi 详情里的「网关」）。
2. 用后台密码登录。
3. 点左上角的菜单 →「**服务**」→「**终端**」。
4. 终端里用户名填 `root`，密码填路由器后台密码。看到下面这样的提示符，就是登录好了：
   ```
   root@OpenWrt:~#
   ```

### 方法 B：后台没有「终端」

- 有 iStore 的：在 iStore 里搜「终端」装上（就是 `luci-app-ttyd`），再按方法 A 打开。
- 或者在手机上装一个 SSH 软件（安卓：JuiceSSH、Termius；苹果：Termius），新建连接：地址填路由器地址，端口 `22`，用户名 `root`，密码填后台密码。

> ⚠️ **装托管版、或者从自建版换成托管版时，不要用路由器面板里的「终端」**：安装过程中面板的连接会被换掉，面板里的终端会中途断开。用上面两种方法之一。

## 第 2 步：粘贴安装命令

复制下面整段，在终端里**长按 → 粘贴**，然后回车：

```sh
# ⚠️ 下面的 hosted-ai 决定装哪个版本：对照第 0 步的表，换成你要的代号，其他地方别动
cd /tmp && wget -O p.tar.gz https://yrlove520.com/dl/openwrt-claude-panel-hosted-ai.tar.gz && tar xzf p.tar.gz && cd openwrt-claude-panel && sh install.sh
```

**改代号的例子：** 要装托管版·纯面板版，就把 `hosted-ai` 改成 `hosted-noai`（在 `ai` 前面加 `no`）。**只改这一处。**

第一行 `#` 开头的是说明，一起粘贴进去也没关系，终端会自动忽略。

粘贴后会先下载（几秒钟），然后看到：

```
==> 安装 AI版·托管版
 ✓ 依赖齐全
==> 复制文件
 ✓ 文件已就位
==> 生成密钥
 ✓ 密钥已就绪
```

> 下载失败（提示 `wget: not found` 或者 SSL 错误）：把命令里的 `wget -O p.tar.gz` 换成 `curl -fL -o p.tar.gz` 再试。

## 第 3 步：输入邀请码（托管版）

屏幕出现下面这行时，粘贴邀请码，回车：

```
邀请码（找提供托管服务的人要）：
```

- 邀请码输错了：会提示「邀请码不对」，让你**再输一次**（最多 3 次）。
- 不小心直接按了回车：会提示「这一项不能空着」，再输一次就行。
- 提示「名额已满」或「邀请码已经用完了」：找给你邀请码的人。

> **自建版**这一步问的是隧道 token 和域名，照[自建版教程](../README.md#选哪个版本一条命令换一个代号)里的说明填；精简版直接回车可以先用临时隧道。

## 第 4 步：保存装完显示的内容

装好后屏幕最后会显示（`xxxxxxxx` 是你的专属网址，每个人不一样）：

```
✓ 开通成功：https://xxxxxxxx.yrlove520.com
================ 安装完成 ================
已安装：AI版·托管版

手机面板：https://xxxxxxxx.yrlove520.com/panel/

登录地址（第一次打开面板时粘贴）：
  https://xxxxxxxx.yrlove520.com/cgi-bin/mcp/（40 位密钥）

或者在手机上直接打开这个链接，自动登录（同样不要发给别人）：
  https://xxxxxxxx.yrlove520.com/panel/#login=（40 位密钥）

Claude 连接器地址（在 Claude「设置 → 连接器 → 添加自定义连接器」里填它；只给 Claude 用，打不开面板）：
  https://xxxxxxxx.yrlove520.com/cgi-bin/mcp/（另一串 40 位密钥）

==================== 配对码 ====================

                    ABCD  2345

================================================
  ① 手机打开上面的「自动登录链接」……
  ② 手机打开这个绑定链接……
       https://yrlove520.com/app?pair=ABCD2345
  ③ 绑定好会自动显示登录码……
```

| 内容 | 用来干什么 |
|---|---|
| 手机面板 | 以后平时打开面板用这个 |
| **登录地址** | 第一次在手机上登录面板 |
| 自动登录链接 | 点开就直接登录，省得粘贴 |
| **Claude 连接器地址** | 只有 AI 版有：填到 Claude 里，**打不开面板** |
| 配对码 / 绑定链接 | 把路由器绑定到官网账号，**10 分钟内有效**，下一步马上用 |

**把登录地址和 Claude 连接器地址复制下来，存在只有自己能看到的地方（比如手机备忘录）。**

> ⚠️ 这些地址里带着密钥，谁拿到都能控制你的路由器：**不要发给别人，不要截图分享**。真的泄露了：面板「系统操作 → 换登录密钥」或「Claude 连接器地址 → 换一个地址」，旧地址马上作废。

## 第 5 步：打开面板、输入登录码

托管版为了安全，**每台手机第一次打开面板要输一次登录码**，登录码在官网账号里拿。所以第一次是这样（配对码 10 分钟有效，一口气做完）：

1. 长按复制「**自动登录链接**」，用手机浏览器打开。面板会显示「**输入登录码**」，先放着别关。
2. 再打开终端里的**绑定链接**（`https://yrlove520.com/app?pair=…`），登录官网账号；没有账号就点「注册」（邮箱 + 密码 + 邮箱验证码）。登录后**自动绑定**这台路由器，并且**自动弹出登录码**。
3. 点弹窗里的「**打开面板**」，登录码自动填好，直接进面板。（或者点「复制」，回到上面第 1 条打开的面板页面粘贴进去，点「确定」。）

输对一次以后，这台手机就不用再输了。进去以后默认是「**首页**」：实时网速、今日流量、在线设备一眼就能看到。

- 登录码 10 分钟有效，用一次就作废。以后要再拿：官网账号页，这台路由器下面点「**获取登录码**」。
- 配对码过期了：在路由器后台终端运行 `cmcp-pair` 再拿一个。
- 官网打不开、急着用：在路由器后台终端运行 `cmcp-logincode`，拿一个应急登录码（同样 10 分钟有效）。

> **自建版**没有登录码，打开自动登录链接就直接进面板，可以跳过第 2、3 步。

## 第 6 步：添加到主屏幕

- 安卓 Chrome / Edge：右上角菜单 →「添加到主屏幕」（Edge 叫「添加到手机」）
- 苹果 Safari：底部「分享」→「添加到主屏幕」
- 想用安卓 App：在 [yrlove520.com](https://yrlove520.com) 下载 App（安装时提示「未知来源」允许一次就行），打开 App 点「粘贴」，或者把登录地址填到「手动添加」框里点「添加」。App 里第一次打开同样要输一次登录码。

> 以前用过面板（比如从自建版换成托管版）：网址变了，主屏幕上旧的图标删掉，重新添加一次。

## 第 7 步（AI 版）：在 Claude 里添加连接器

1. 打开 Claude（App 或网页）→「设置」→「连接器」→「**添加自定义连接器**」。
2. 名字随便填（比如「路由器」），地址填第 4 步的「**Claude 连接器地址**」（不是登录地址），保存。
3. 新开一个对话，试试：「看看路由器现在的状态」。

忘了连接器地址：面板「系统操作 → Claude 连接器地址」里能复制。

> 以前用「登录地址」加过连接器（v1.3.0 及更早）：托管版现在不能用了，把旧的删掉，用连接器地址重新添加。

## 第 8 步：开推送

面板 →「断线记录」→「手机通知」→「开启通知」，浏览器问要不要允许通知时点「允许」。断网、断电、隧道断开、新手机登录面板时会推送到手机。

## 第 9 步：家里其他手机

在已经登录的手机上：面板「系统操作 → **添加新手机**」→ 点一下二维码显示出来 → 用新手机的相机扫。托管版的新手机打开后还要输一次登录码（官网账号页 → 这台路由器下面「获取登录码」）。

家里人也想在官网看到这台路由器：让他注册自己的官网账号，你在面板「系统操作 → 绑定到账号」拿一个配对码给他。

不用了、或者手机要给别人：面板侧边栏最下面「**退出登录**」（或者「系统操作 → 退出登录」）。不认识的手机：「系统操作 → **已登录的手机**」里移除。

## 以后升级

有新版本时，面板首页会提示「路由器有新版本」，点「**一键更新**」就行：路由器自己下载、校验、安装，设置都保留，不会断网，面板断开十几秒后自动回来；装不好会自动退回原来的版本。

> v1.3.0 及更早的版本还没有一键更新，要在路由器后台终端里把第 2 步的命令再运行一次（不用再输邀请码），以后就能一键更新了。

## 常见问题

**粘贴命令后，邀请码那一行一闪而过，提示「托管版需要邀请码」？**
旧版安装脚本的问题，新版已经修好。遇到了也不要紧，在终端里接着输入（把「邀请码」换成你的）：
```sh
sh install.sh --invite 邀请码
```

**连着家里的 Wi-Fi 时面板打不开，换成手机流量就好？**
连家里 Wi-Fi 时，打开面板的流量会经过 OpenClash 的代理节点，节点卡了就打不开。面板每 3 分钟自动检查，代理打不开会自动改走直连（需要先在面板「拉黑名单」里启用过一次规则集）。急的话先用手机流量打开。

**「终端」到底是哪个？在面板终端里输 `password` 提示 command not found？**
有两个终端：
- **路由器后台的终端**：浏览器打开路由器后台（`http://192.168.1.1`）→「服务」→「终端」，用户名 `root`，密码是后台密码；或者用 SSH。**安装、升级托管版、`cmcp-pair`、`cmcp-logincode` 都在这里运行。**
- **手机面板里的终端**：装好以后面板「工具 → 终端」。它已经是 root 身份，不用登录，`password` 不是命令，所以提示 not found。平时查东西可以用它，但安装和升级不要在这里做（安装中途面板会断开）。

**打开面板一直让我输登录码？**
托管版每台手机第一次要输一次。清除了浏览器数据、换了浏览器、点了「退出登录」，都算新手机，要重新输。登录码在官网账号页拿；账号里没有这台路由器，先用配对码绑定。

**登录码提示「不对或已过期」？**
登录码 10 分钟有效、只能用一次，重新点「获取登录码」拿一个新的。连续输错 10 次要等 10 分钟。

**提示空间不够？**
终端运行 `df -h /overlay` 看剩余空间，不到 40 MB 的话先清理或扩容。

**升级到新版？**
面板首页提示有新版时点「一键更新」（v1.3.1 起）。也可以把第 2 步的命令在路由器后台终端里再运行一次，托管版不用再输邀请码，网址、密钥和设置都保留。

**卸载？**
```sh
cd /tmp/openwrt-claude-panel && sh uninstall.sh
```
`/tmp` 重启后会清空，提示找不到目录的话，先把第 2 步命令里 `&& sh install.sh` 之前的部分运行一次（重新下载解压），再运行上面的卸载命令。托管版卸载时专属网址会自动交还。

**从自建版换成托管版要注意什么？**
网址会变成 `xxxxxxxx.yrlove520.com`；每台手机第一次打开要输登录码；Claude 连接器要换成新的连接器地址；推送要重新开一次；以前的云端备份留在旧的服务上，新的备份从装好开始算。登录密钥和面板里的设置都保留。
