常见问题

反馈过问题 查处理进度

专属网址打不开 提示停用或到期
家里上网和路由器设置不受影响 停的只是专属网址 推送和云端备份
已到期 在账号页点「续期」或「申请续期」 暂停超过 30 天会被删除
已停用 在显示的日期前联系服务提供者恢复 网址不变
账号里没有了 在账号页「装新路由器」重新领一个安装码 再运行一次命令 设置保留 网址会换
试用快到期了
到期前 3 天会推送提醒
在账号页点「申请续期」 审核通过自动续上 有续期码直接点「续期」 不用重装
换了手机怎么登录
在新手机登录账号页 点「打开面板」 登录码会自动带上
官网打不开时 在路由器终端运行 cmcp-logincode 拿应急登录码
连家里 Wi-Fi 打不开 用流量可以
通常是代理插件在重启或节点卡住 面板会自动改走直连 一两分钟后再试
遇到问题或想要新功能
面板侧边栏底部「问题反馈」 可以附截图 发出后会拿到受理编号
功能开不了时面板会说明原因 点「报告这个问题」 内容已自动填好
不想用托管服务
用自己的 Cloudflare 账号和域名 或只在局域网使用 自建版和教程在 GitHub
